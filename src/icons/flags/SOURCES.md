# Language picker flags

These PNG files are stored locally and bundled with the application; opening a language picker makes no network requests.

Downloaded unchanged from [Flagpedia / FlagCDN](https://flagpedia.net/download/api), at 96 × 72 pixels. The provider identifies these country flag images as [public domain, free for commercial and non-commercial use](https://flagpedia.net/download), based on Wikimedia Commons flag designs. Exact source URLs and SHA-256 hashes are listed in [sources.json](sources.json).

`EXTRA_FLAG_COUNTRIES` maps language codes to representative country flags. Several languages can share one flag; a flag is a visual cue, not a definition of where the language is spoken. The original 16 language icons remain separate assets.
