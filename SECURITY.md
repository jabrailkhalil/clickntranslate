# Security policy

Do not open a public issue for a vulnerability that exposes user data, permits
code execution, bypasses package verification, or leaks credentials. Send a
minimal report to `jabrailkhalil@gmail.com` with the affected version, impact,
reproduction steps, and a safe proof of concept. Remove personal screen text,
documents, tokens, and translation histories before sending evidence.

General bugs and feature requests belong in the public GitHub issue tracker.
Only the latest release and the current default branch receive security fixes.
