# 简体中文（中国）

产品名称：`Click'n'Translate`

简短说明：`Windows 上出色的屏幕翻译与 OCR 工具，支持全局快捷键和离线引擎。`

## 说明

Click'n'Translate 是 Windows 上优秀的一体化屏幕翻译工具。它可以翻译游戏、图片、视频、文档、远程桌面以及无法直接复制的界面文字。

按下全局快捷键，框选任意区域，即可快速获得识别结果或翻译，同时保持当前工作流程。您可以选择快速的在线翻译，也可以安装 Argos 和 Hy-MT 语言包进行离线翻译。四种 OCR 引擎适合不同文字和图像场景。

无需注册账号。历史记录可选并保存在本机。OCR 和离线翻译在设备上完成；选择在线引擎时，仅会发送您要求翻译的文字。

## 功能

- 选定区域与全屏即时 OCR 翻译
- 从任何应用中复制无法选择的文字
- 四个可自定义的全局快捷键
- Google、MyMemory、Lingva 和 LibreTranslate 在线引擎
- Argos Translate 和 Hy-MT 离线引擎
- Windows OCR、Tesseract、RapidOCR 和 EasyOCR
- 16 种可选 OCR 与翻译语言
- 可选的本地复制与翻译历史
- 深色与浅色主题
