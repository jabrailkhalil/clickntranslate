Одна программа — разные задачи

Текст становится полезным, как только вы его увидели.

Выбирайте нужный результат вместо того, чтобы переносить один скриншот между несколькими сервисами.

01

Динамический перевод

Выберите одну или несколько областей. Неизменившиеся кадры пропускаются, а оверлеи обновляются вместе с исходным текстом.

Ctrl + Alt + G
02

OCR области

Копируйте текст из картинок, видео, игр, сканов и интерфейсов, где выделение запрещено.

Ctrl + Alt + C
03

Перевод экрана

Переведите отдельную область или разместите перевод поверх всего экрана.

Ctrl + Alt + T / F
04

Выделенный текст

Переводите выделение или заменяйте его в той же программе с сохранённой языковой парой.

Ctrl + Alt + Q
05

Документы

Открывайте текст, Word, PDF, HTML и RTF: оригинал и перевод остаются рядом.

Ctrl + O

Экран ваш — маршрут тоже

Выберите движок под конкретный текст.

Шрифт, язык, масштаб и контраст влияют на результат. Устанавливайте только те компоненты, которые нужны вам.

Приватность без расплывчатых обещаний

Всегда понятно, куда отправляется текст.

OCR выполняется локально. Argos Translate и Hy-MT после установки пакетов тоже переводят на компьютере. При выборе онлайн-провайдера ему отправляется текст, который вы запросили перевести.

Истории копирования и перевода локальны и включаются отдельно. В программе нет аналитики разработчика.

О предупреждениях антивирусов в Windows

Сборка Windows пока не подписана сертификатом. Глобальные горячие клавиши, захват экрана, буфер обмена, автозапуск и обновление могут вызвать общее эвристическое предупреждение. Скачивайте программу только из официального репозитория, сверяйте контрольные суммы и сообщайте о новых детекциях для проверки.

Короткие ответы

Перед установкой.

Программа работает без интернета?

Да, после установки OCR-языка и пакета Argos Translate или Hy-MT для нужного направления. Онлайн-провайдерам по-прежнему требуется интернет.

Можно переводить игры и видео?

Да. OCR читает пиксели выбранной области, поэтому текст не обязан выделяться. Точность зависит от языка, шрифта, масштаба, контраста и движка.

Есть версия для Linux?

Да. На странице релиза доступны x86_64 AppImage и переносимый TAR-архив. Интеграция захвата может зависеть от окружения рабочего стола.

Все горячие клавиши можно изменить?

Да. Любую глобальную комбинацию можно поменять или очистить. OCR, экран, выделение, замена и динамический режим хранят отдельные языковые пары.

Какие документы поддерживаются?

TXT, Markdown, DOCX, PDF, HTML, HTM и RTF. Результат сохраняется как текст, Markdown или локальная сессия.
