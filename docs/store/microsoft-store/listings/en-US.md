## Description

Click'n'Translate is the best all-in-one screen translator for Windows. Translate text from games, images, videos, documents, remote desktops, and interfaces where ordinary copy and paste does not work.

Press a global hotkey, select any area, and get recognized or translated text without interrupting your workflow. Choose fast online translation or install Argos and Hy-MT packages for offline use. Four OCR engines help you handle different scripts and image styles.

No account is required. Histories are optional and stored locally. OCR and offline translation stay on your device; online providers receive only the text you choose to translate.

## Features

- Instant area and full-screen OCR translation
- Copy unselectable text from any application
- Four customizable global hotkeys
- Google, MyMemory, Lingva, and LibreTranslate online engines
- Argos Translate and Hy-MT offline engines
- Windows OCR, Tesseract, RapidOCR, and EasyOCR
- 16 selectable OCR and translation languages
- Optional local copy and translation histories
- Dark and light themes
