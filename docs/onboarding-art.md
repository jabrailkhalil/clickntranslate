The first-run cards use the static, transparent illustration
`src/icons/onboarding/click-guide.png`. It was created with the built-in OpenAI
image generation tool using the existing Click preview as its identity reference.
It adds no animation timer and does not enable or change the desktop companion.

Prompt:

> Use case: identity-preserve. Asset type: transparent onboarding-card companion
> illustration for ClicknTranslate. Use the provided image as the exact character
> identity reference, not a target UI. Create a polished high resolution full-body
> 3D render of Click, the same cute small cream-and-lavender robot with soft rounded
> square head, big blue eyes, lavender headphone-like sides, cream face and belly,
> short lavender arms and legs. A friendly helpful guide pose: standing at a slight
> three-quarter angle, facing the viewer, warm smile, one open hand raised gently
> toward the adjacent instructions, the other relaxed. Preserve his recognizable
> proportions and materials. Studio-quality soft lighting, crisp natural edges,
> restrained purple highlights. Full body including feet, with generous transparent
> padding. No scenery, no ground plane, no floating confetti, no props, no text,
> no letters, no badges, no watermark. Genuine transparent alpha background;
> single character only.

The guide starts with language and theme and uses the real settings controls.
Accepting the chat scenario enables select-all before replacing, then shows the
independent replacement language pair and the actual assigned shortcut. Skipping
the scenario leaves existing choices intact. No typing, clipboard writes, chat
messages, model downloads or API requests are triggered by the tour itself.
