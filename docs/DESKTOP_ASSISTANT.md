# Маскот Click’n’Translate

Актуальный набор — Pets v18: Клик, Док, Честер, Блинчик, Раф и Лола.
Персонаж выбирается стрелками на платформе во вкладке «Маскот».

- Слева находятся галочки видимости, положения поверх окон и реакций на события.
- Справа — режим отображения, размер и непрозрачность.
- В главном меню показан один статичный ярлык выбранного персонажа; клик открывает настройки.
- На рабочем столе клик по персонажу открывает меню перевода и настроек.
- Ходьбы и ручного выбора эмоций нет. Реакции связаны с действиями приложения.
- Семь нативных анимаций используют цельные кадры; взгляд имеет шестнадцать направлений.
- При захвате экрана персонаж скрывается. Скрытые предпросмотры не анимируются.
- Собственные изображения остаются статичными; положения и настройки сохраняются.

Сценарии, формат ресурсов и снимки интерфейса описаны в
[документации набора](mascots/pets-v18/README.md).
[Промпты](mascots/pets-v18/PROMPTS.md) и
[проверки](mascots/pets-v18/TESTING.md) относятся к актуальным ресурсам.

```powershell
python tools/preview_mascots.py
python tools/run_mascot_app.py
python tools/qa_mascot_motion.py OUTPUT_DIRECTORY
```

Первый инструмент открывает мастерскую, второй — приложение с отдельным профилем,
третий экспортирует нативные анимации и 42 статичные позы.
