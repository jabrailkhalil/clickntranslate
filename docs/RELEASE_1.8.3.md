## What's new

- Manage offline engines, language packs and API connections in one place. Track a download in the background or cancel it.
- The Windows selection button reads highlighted text through accessibility. Translate and replace checks that the original editor still has focus before inserting the result.
- Add personal images to the portable companion gallery. Hiding the desktop companion now persists across restarts.
- Language flags stay sharp when you enlarge the interface. FAQ text keeps the selected scale when you reopen it, and Arabic help reads right to left.
