На этой Windows 10 build 19045 Qt-окна с `WA_TranslucentBackground` отвергали
`SetWindowDisplayAffinity(0x11)` с WinError 8. Прежний запасной путь менял opacity
перед каждым захватом, вызывая мерцание. Теперь Windows использует обычную
нативную поверхность с формой `QRegion` и проверенным `WDA_EXCLUDEFROMCAPTURE`.
Пустая маска Qt раскрывает всё окно, поэтому для полностью скрытого содержимого
нужна непустая маска за пределами окна. Не возвращать прежний opacity-fallback
на Windows. Mac сохраняет платформенный механизм исключения окон; Linux имеет
отдельный путь временного скрытия. Новый интерфейс нужно нативно проверить на Mac.

`PairedTranslationOverlay.region` всегда обозначает источник OCR;
`output_rect` — отдельное место вывода. На Windows под полупрозрачным фоном
рисуется снимок места вывода, а не исходного текста. Геометрию вывода нельзя
подменять геометрией источника. Длинный текст не должен раздвигать выбранное окно.

Шаблоны записываются через `QSaveFile` в `data/dynamic_templates.json`; повреждённый
файл не перезаписывается. Пользовательские настройки, история и шаблоны локальны.
К моменту завершения разработки пользовательских шаблонов ещё не было; тесты
использовали отдельные временные хранилища. `data/config.json` не изменён.
