# Проверки Android 0.3.1

Актуальная проверочная сборка без выпуска релиза: [APK 0.3.2](../artifacts/android/README.md) и [изменения интерфейса](android-preview-v2.md). Ниже сохранён исторический отчёт 0.3.1.

Проверено 3 октября 2026 года. Сборка предназначена для ручного тестирования. GitHub Release не опубликован.

## Проверки новой версии

- Все 1632 модульных теста пройдены: 437 классов, без ошибок и пропусков.
- Все 8 проверок интерфейса на Robolectric Android API 35 пройдены: смена шести языков, первый запуск на русском, сохранение бумажной темы, выбор режима перевода, сохранение черновика при смене языка, значки и импорт изображений.
- Все 14 снимков Paparazzi сформированы и проверены визуально: основные экраны, бумажные темы, карточки режима, категории, готовность, значки и иллюстрация исправления.
- Все 7 Python-тестов словарных пакетов пройдены.
- Полнота 2209 переводимых строк и совпадение параметров форматирования подтверждены для всех шести локалей.
- APK имеет валидную подпись v2, пакет `dev.clickn.translate.preview`, versionCode 4 и 15 библиотек ARM64, включая CPU-варианты и Vulkan. Архив целостен; тестовые инструменты в него не входят.
- Векторный логотип проверен на плотностях 160, 320 и 640 dpi. Растровые ресурсы больше не перекрывают его.

Описание изменений: [Android 0.3.1](android-changes.md).

## Изменения и аудит

Проверены маршруты главного экрана, мастер первого запуска, настройки сервисов, обработка входящих изображений, хранение ключей, профили перевода, история текста, отмена запросов и работа фоновых задач галереи.

Исправлено:

- Фоновые задачи новых онлайн-сервисов и NiuTrans теперь требуют сеть и повторяются с учётом сетевых ошибок.
- Проверка причин ошибки ограничена и выдерживает циклические цепочки исключений.
- Экспортированная точка входа для фото принимает только `content://` URI; ссылки на приватные файлы приложения и сетевые URL отклоняются.
- Копирование одного входящего фото ограничено 50 MiB; незавершённый файл удаляется при ошибке.
- История текста исключена из облачного резервного копирования и переноса на другое устройство.
- Отменённые запросы перевода и проверки соединения не перезаписывают результат нового запроса.
- LibreTranslate использует свой ключ. Ключ профиля привязан к адресу сервера; адреса Lingva и LibreTranslate сохраняются в профилях.
- HTTP-ответы новых сервисов ограничены 1 MiB, перенаправления отключены, чтение выполняется в рабочем потоке, отмена закрывает запрос.
- Возврат к системному языку интерфейса сбрасывает ранее выбранную локаль. Целевой язык новой установки определяется по языку системы.
- Мастер обновляет статус разрешений при возврате из Android и сохраняет шаг при открытии OCR, моделей и плавающей кнопки.
- Для MyMemory и ML Kit мастер требует явный язык оригинала.
- Открытие системных настроек использует запасной маршрут либо понятное сообщение, если производитель устройства не поддерживает переход.
- Проверки поиска расширенных настроек сопоставлены с текущими разделами; исправлена регистрация NiuTrans и поиска статистики производительности.

Ключи по-прежнему обрабатываются защищённым хранилищем. Экспорт настроек и диагностика используют общую политику исключения секретов и приватных параметров соединения. Дополнительные журналы и скриншоты включаются только через соответствующие настройки.

Android Lint: **0 ошибок**, 868 предупреждений и 42 информационных замечаний. Большая часть новых предупреждений относится к словарной проверке переводов. Полный прогон сборки, тестов и Lint завершён успешно.

Сборка использует KSP2, Hilt 2.54 и Room 2.7.2, чтобы избежать повторного подхватывания промежуточных Java-классов. Схемы баз данных приложения не изменены.

Пять изображений интерфейса получены из рабочих Compose-компонентов через Paparazzi: главный экран в светлой, тёмной и AMOLED-теме, результат текстового перевода и настройки. Они находятся в `app/src/test/snapshots/images/`. Проверены читаемость текста, расположение действий и отсутствие видимых перекрытий. Это отрисовка Android Layoutlib, а не запуск на физическом телефоне.

Снимки запускаются отдельно от обычных проверок:

```bash
./gradlew -PuiSnapshots :app:recordPaparazziDebug --tests dev.clickn.translate.ui.MobileScreenshotTest
```

Проверки Activity и значков запускаются отдельно:

```bash
./gradlew -PpreviewBuild -PruntimeUiTests :app:testDebugUnitTest --tests '*RuntimeTest'
```

Дополнительная зависимость для снимков подключается только с `-PuiSnapshots` и не включается в APK. В обычном прогоне выполняются тесты приложения без снимков.

## Ограничения проверки

- Физический телефон и Android-эмулятор не использовались. Системное согласие на захват, специальные возможности, Shizuku, ограничения батареи и поведение оболочек производителей требуют проверки на устройстве.
- Запросы Lingva, MyMemory и LibreTranslate проверены через контролируемый HTTP-транспорт: адрес, параметры, ключи, кодирование, ошибки, ограничения размера, отмена и разделение кэша. Доступность публичных серверов не гарантируется; при пробных запросах некоторые серверы возвращали ограничения или ошибки.
- Платные API-сервисы не проверены с реальными учётными данными пользователя.
- Новые основные экраны имеют подготовленные переводы на все шесть языков. Для большого набора расширенных строк использован машинный перевод в русском, немецком, французском и испанском; необходима редактура носителями языков. Полнота строк и совпадение параметров форматирования проверяются автоматически.
- Нет утверждения об отсутствии всех возможных уязвимостей или ошибок. Аудит охватывает перечисленные изменения и основные точки входа.

Для установки и ручной проверки см. [пошаговую инструкцию](android-setup.md).
