# Проверка обновлений macOS и Linux, 22 октября 2026

До этого аудита полный нативный цикл обновления не был подтверждён. Проверки
подготовки пакета, подписи и обычного запуска не заменяли такую проверку.
Ранее подготовленные архивы 1.8.2 не считаются финальными.

## Исправления

- Ошибки сервера и отсутствие совместимого пакета остаются на встроенной
  странице обновления с повторной проверкой. Переход на страницу GitHub убран.
  Исправлены тексты на всех восьми языках интерфейса.
- После обновления приветствие и начальные подсказки не задерживают готовность
  основного окна. Обычная настройка показа приветствия сохраняется. В прежнем
  бинарнике включённое приветствие блокировало подтверждение и вызывало откат.
- Mac проверяет полную подпись и требование подписи установленного приложения.
  Прежний сертификат закреплён даже без Team ID. Нативная проверка приняла
  прежний сертификат и отклонила корректно подписанное ad-hoc приложение.
- После передачи подготовленной копии POSIX updater удаляет скачанный архив.

Источник файлов остаётся GitHub Releases. Программа сама получает метаданные,
загружает пакет, сверяет SHA256, подготавливает замену, закрывается и запускает
новую версию. Ручное скачивание пользователем в браузере в этот путь не входит.
Системные установки Linux, которыми управляет пакетный менеджер, updater не
перезаписывает.

Настройки, маркеры моделей, скрытые и личные файлы сохранились. При откате
AppImage завершался именно GUI внутри runtime; восстановленный GUI получил
другой PID. Дополнительная проверка inode подтверждает реальную замену/возврат
файла или каталога, включая случай одинаковых версий тестового пакета.

Контрольные бинарники Mac (с прежней подписью) и Linux portable с исправлением
прошли обновление 1.8.1 → 1.8.2 с включённым `show_update_info=true`: готовность
подтверждена, окно отвечает, настройка осталась включена.

Отдельный итоговый набор: 92 теста на Windows, 92 на нативном Mac и 92 на
нативном Linux — все пройдены, реальные пользовательские данные не изменены.

## Границы проверки

`tools/qa_posix_update.py` нажимает настоящие кнопки Qt в исходной Python-версии.
Только определение установленного frozen-пути и текущая версия контроллера
симулируются, чтобы использовать существующие пакеты до новой сборки.
HTTP-запросы, загрузка, SHA256, подготовка, отдельный updater, замена, закрытие,
запуск и подтверждение от настоящего собранного GUI выполняются рабочим кодом.
Тест не подделывает успешное подтверждение запуска.

Используется локальный HTTP-сервер с форматом GitHub Releases. Это проверка
механизма, а не будущего опубликованного релиза или CDN. Старые публичные Mac
и Linux версии не приобретают новый updater автоматически от изменения
исходников. Все установки, профили и IPC-сокеты тестовые и изолированы.

Рабочее приложение на Mac и исходный репозиторий с сохранёнными изменениями
не заменялись этим аудитом. Контрольные бинарники предназначены для теста;
публикация, тег и финальная упаковка не выполнялись.
