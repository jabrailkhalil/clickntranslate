# Сетевой перевод: границы проверок

Провайдер выбирается явно. Ошибка не переключает обработку на другой сервис. По умолчанию OCR/MT локальные; сетевые MT и OCR выбираются независимо. Выбранный облачный OCR получает изображение, выбранный онлайн-MT — подготовленный текст. Устанавливаемые модели требуют отдельной загрузки; это не отправка распознанного текста.

## MyMemory

Независимый адаптер использует официальный HTTPS `/get` с `q` и `langpair`. Ключ необязателен; интерфейс поддерживает анонимный запрос. По [технической спецификации](https://mymemory.translated.net/doc/spec.php) сегмент ограничен500 UTF-8 bytes. Pipeline разделяет независимые абзацы до подготовки bounded sentence-first chunks; несколько абзацев одним сегментом не объединяются.

Текущий [анонимный лимит](https://mymemory.translated.net/doc/usagelimits.php) —5000символов в сутки. Лимиты принадлежат сервису и могут измениться; клиент обрабатывает отказ и не пытается обходить квоту. Автоматический повтор OkHttp отключён. [Условия сервиса](https://mymemory.translated.net/terms-and-conditions) описывают длительное хранение отправленных сегментов и участие внешних MT-партнёров; выбор этого провайдера означает сетевую обработку.

`MyMemoryLiveIntegrationTest` — отдельная opt-in проверка Android-адаптера: флаг `runLivePublicProviderTests=true`, одна собственная синтетическая фраза EN→RU, без аккаунта, ключа, изображения или пользовательского текста. Без этого флага проверка явно пропускается. Настоящий сетевой сбой или квота при включённом флаге считаются FAIL. Фактический ответ, устройство, исходный commit и результат нужно брать из текущего QA-журнала; наличие теста не означает PASS. Один ответ не оценивает качество всего сервиса.

## Остальные адаптеры

Контрактные mock-проверки официальных API не доказывают доступ аккаунта, текущую квоту, entitlement модели или качество реального перевода. Платные Google Cloud/OpenAI/Anthropic/DeepL/DeepSeek и облачный TTS требуют доступных пользовательских аккаунтов. Lingva/LibreTranslate/custom требуют явно настроенного сервера. Их реальный статус указан отдельно в сравнительной таблице; generic HTTP не считается совместимостью с произвольным прежним протоколом.
