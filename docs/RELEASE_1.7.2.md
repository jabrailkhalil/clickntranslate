# Click'n'Translate 1.7.2 — draft

Status: development build for testing; this version has not been published.
The Windows test package is unsigned.

## Changes

- Refined the main window header and translation controls.
- Improved the desktop assistant's rounded edges and separated its assistant
  controls from program actions.
- Added a compact desktop mascot control and tray action.
- Added an option to disable button hover tips.
- Kept the translation engine selection local to each translation window.
- Synchronized the application, updater, launcher, installer and package
  metadata at version 1.7.2.

Download links and `CITATION.cff` continue to describe the published 1.7.0
release until a public release is approved.
