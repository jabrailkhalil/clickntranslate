# Click’n’Translate Android 1.9.4 — историческая контрольная точка

Сохранены APK исторического среза **1.9.4 / code 32**, исходники `2131073d4cc1d0f2911a2f85bf3daef322808a00`. Это не текущая целевая версия для обновления пользователей. Контрольная точка имеет известные ошибки качества; полное соответствие всем возможностям архива не объявляется.

- [Full debug ARM64 APK](../artifacts/android/ClicknTranslate-1.9.4-full-debug-arm64.apk): **90 614 197 B**, SHA-256 `24a0ad77817e06ee6e8509a993fc60c2e362b5acda58a26949e17fe250eeb198`.
- QA APK на рабочем столе: `ClicknTranslate-Android-1.9.4-QA.apk`, **64 671 048 B**, SHA-256 `89ba8bfa769601586af4adae99c5440715215d179aefc78320fe03e474a49078`.
- Full имеет пакет `dev.clickn.translate.debug`, QA — `dev.clickn.translate.validation`. Production release не выпускался, production key не заменялся.

Архивные авторские UI и модули переносились с разрешения пользователя; это не заявление о clean-room переписывании. Работы касались Android, main и настольная версия не менялись.

Для этой сборки завершены assemble Debug/Validation/AndroidTest, lint и **40 целевых unit-тестов / 10 suites: 0 failures, 0 errors**. Lint: **0 ошибок, 977 warnings, 42 informational**. Весь исторический набор заново не запускался. Отдельный native Android strict reference-тест **FAIL: 1/1** — на собственном эмуляторе `OCR→O` (потеря C/R), при наличии всех трёх независимых блоков. На физическом телефоне `OCR→OR`. Тест не ослабляли; эмулятор остановлен.

Известные ограничения: **потеря C в mixed OCR**, **«две книги» вместо одной в Hy-MT2**, непроверенные физический Android 8, runtime 16 KB, слышимость TTS, платные API и остальные OEM/языковые корпуса. Обычная сборка и работа приложения не требуют доступности production-ключа; production-обновление прежних установок этой передачей не подтверждается.

На телефоне захват остановлен, MediaProjection null. Собственная QA-фикстура и 2,392 GB публичных staging-копий моделей удалены, импортированные QA-модели сохранены, настройка питания восстановлена. Приватные данные других пакетов не читались.

Точный [отчёт 1.9.4](qa/archive-restoration/phone194/README.md) содержит APK-идентичность, реальные ограничения и небольшой набор собственных свидетельств; [машинный отчёт](qa/archive-restoration/phone194/report.json) — SHA-256 инвентаря. Старые отчёты сохранены как исторические.
