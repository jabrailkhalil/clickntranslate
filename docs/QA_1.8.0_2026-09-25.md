# Click'n'Translate 1.8.0 — сборки и проверка, 25 сентября 2026

## Статус

Подготовлены и проверены тестовые сборки Windows x64, Linux x86_64 и macOS arm64.
На момент завершения QA публикация не выполнялась. Затем пользователь
разрешил выпуск 1.8.0 для всех трёх систем с раскрытием ограничений подписи.
Публичные бинарники совпадают с проверенными; в Windows-именах удалено `test`.
Публичный архив исходников дополнен актуальными README и описанием релиза.
Подписи имеют имя `jabrailkhalil`. Для Windows и Mac использованы собственные
тестовые сертификаты; публичное доверие SmartScreen/Gatekeeper ими не обеспечивается.

Последние изменения: исправления компаньона на Mac и единый тонкий стиль
прокрутки во всех окнах. После этих правок повторно проверены и пересобраны
Windows, Linux и Mac. Итоговый снимок исходников включает общий модуль стиля.

Исходники: рабочий каталог поверх commit
`20787e4` с текущими незакоммиченными изменениями. Снимок исходников включает
эти изменения; один checkout указанного commit их не содержит.
Прикладные изменения перенесены на все три сборочные машины. В итоговый снимок
также входят исправления средств macOS QA и подписи, сделанные после первых сборок.

Результаты находятся в `releases/qa-1.8.0-20260925/`.

## Подписи jabrailkhalil

- **Windows:** Authenticode SHA-256 у launcher, GUI, OCR/Argos/updater EXE,
  установщика и встроенного деинсталлятора. Есть RFC 3161 timestamp DigiCert.
  Независимая проверка `osslsigncode` с явно переданным публичным сертификатом
  прошла для пяти EXE и установщика; изменённый контрольный файл отклонён.
  Встроенный деинсталлятор подписан Inno до упаковки, что отражено в логе.
  Windows показывает `UnknownError` для цепочки собственного сертификата:
  сертификат не добавлялся в Trusted Root/Trusted Publisher. Это не результат
  проверки доверенного публичного издателя. Антивирусная проверка недоступна:
  `Get-MpComputerStatus` вернул ошибку загрузки провайдера Defender.
- **macOS:** подписаны все 228 Mach-O файлов, 12 framework bundles, `.app`
  и DMG. У каждого нативного компонента проверены `Authority=jabrailkhalil`
  и целостность `codesign`; вся `.app` прошла `--deep --strict`.
  Это local development signing без Apple Developer ID, hardened runtime
  и нотариализации. Существующая установленная программа и прежний ключ сохранены.
- **Linux:** отдельные OpenPGP/Ed25519 `.asc` подписи AppImage и tar.gz.
  Итоговый `SHA256SUMS.txt` также подписан и охватывает весь набор артефактов.
  `.asc` проверяются отдельно; они не включают автоматическое доверие окружения Linux.
- Публичные сертификаты/ключ лежат в `certificates/`. Закрытый Windows-ключ
  неэкспортируемый и хранится в CurrentUser; Mac-ключ — в отдельной связке ключей;
  Linux-ключ — в защищённом каталоге сборочной VM. Приватные ключи и пароли
  в файлы сборок не включены. Инструкция и отпечатки — `SIGNATURES.md`.
- Из-за расхождения часов с RFC 3161 сервером тестовый Windows-сертификат
  имеет запас в один день до начала срока действия. После исправления файлы
  переподписаны и повторно проверены. Системные часы не изменялись.

## Единый стиль прокрутки

- Вертикальная и горизонтальная полосы используют один `scrollbar_styles.py`:
  6 логических пикселей, скругление 3 px, прозрачная дорожка, без стрелок.
- Общий стиль установлен для всего QApplication, включая новые окна и отдельные
  выпадающие списки. Удалены локальные варианты шириной 8–12 px и фиксированные
  размеры полос таблиц языковых пакетов.
- Цвета следуют теме окна, в том числе при переключении темы и наведении/нажатии.
  Меняется только оформление самой полосы; общий stylesheet при смене темы
  не переустанавливается, чтобы не нарушать масштабирование текста.
- Проверены таблицы, списки, QTextEdit, QTextBrowser и QScrollArea; обе оси,
  колесо, перетаскивание, отсутствие кнопок со стрелками и масштаб 80–200%.
  Полоса остаётся тонкой при увеличении текста. 15 отдельных регрессионных тестов.
- Дополнительно проверены реальные окна перевода, справки, выбора языка,
  настроек/языковых пакетов и разрешений macOS существующими UI тестами.

Финальный Windows-прогон разделён на два изолированных offscreen-процесса:
все 110 файлов тестов выполнены ровно по одному разу; отдельные JUnit/log и

проверен 10 раз подряд. Состояние масштаба после новых тестов восстанавливается.

Пропуски относятся к условиям конкретных платформ и окружений; причины
каждого пропуска сохранены в полных логах. JUnit учитывает subtests отдельными
записями, поэтому его общий счётчик выше количества основных тестов.
Изолированные полные прогоны завершились с `user_data_unchanged: true`.
Дополнительная проверка настоящего Application Support на Mac подтвердила
сохранность настроек, историй и моделей; диагностический `ocr_debug.log`
пополнился записями. Это отдельно отражено в `macos/user-data-final.json`.
Повторная проверка после последних правок стартовых окон использовала новую
точку сравнения после ручной работы пользователя: `macos/user-data-startup-final.json`
подтверждает полное совпадение файлов до и после финальной сборки и проверок.

Проверены общая логика OCR/перевода, разбиение текста, маршрутизация провайдеров,
отмена и ошибки, сохранение настроек, темы и размеры UI, режимы результатов,
динамический вывод, установщик, обновление и откат, упаковка, подписи и
платформенные адаптеры. Имитация другой платформы в unit-тесте не считается её
нативной проверкой.

## Нативные и прикладные проверки

### Windows

- Отдельные нативные UI-прогоны: 40 проверок велкома, меню языков, стрелки
  отправки и выбора языков; 45 проверок стилей, настроек и освобождения Qt
  объектов. Все прошли. Новый текст велкома проверен на шести языках.
- Настоящий Windows OCR: три колонки при масштабах захвата 100/125/150/200%.
- Динамический перевод: новый кадр, прокрутка, изменение диалога, удаление
  устаревшего текста. Источник — отдельный процесс Windows; проверены правильный
  HWND, вывод поверх источника, продолжение после периода восстановления фокуса
  и обновление при скрытой панели управления.
- В этих сценариях OCR настоящий, перевод детерминированный тестовый. Проверки
  не означают успешную работу во всех играх или эксклюзивном fullscreen.
- Финальная упакованная программа запущена в изолированной копии в режиме
  `--layout-editor`: версия 1.8.0 подтверждена ответом приложения, видимые окна
  обнаружены, проверены 3955 программных файлов. Обычный холодный запуск Windows
  вне этого режима отдельно не проверялся, поскольку пользовательский экземпляр
  приложения оставался работающим.
- Реальные компилируемые тесты обновления Inno/ZIP проверяют успешную замену,
  откат и сохранение настроек, историй и вложенных моделей. Финальный большой
  установщик собран, но отдельно не устанавливался поверх пользовательской
  установки.

### Linux X11

- Полный прогон выполнен в отдельном каталоге Ubuntu VM; существующий Linux
  проект не изменялся.
- Нативный X11-сценарий использует Tesseract: независимая область вывода,
  только перевод, перекрытие источника, исключение оверлея из захвата,
  отсутствие мерцания при раздельных областях, перемещение и изменение размеров,
  сохранение шаблона, скрытая панель и остановка сессии. Все проверки прошли.
- Обе финальные упаковки запущены обычным способом в отдельном Xvfb:
  подтверждены версия 1.8.0, команда показать окно через IPC и штатное завершение.
  Скриншот настоящего интерфейса AppImage просмотрен.
- AppImage проверен с распаковкой во временный каталог. Монтирование AppImage
  через FUSE и запуск двойным щелчком в пользовательском DE отдельно не проверены.

### Linux Wayland

- Два прогона в отдельной сессии Sway: обычная плотность и смешанный масштаб
  с DPR 2 на первом экране.
- Настоящий Screenshot portal, два экрана, отрицательное начало координат,
  соответствие цветов/размеров/логических координат и round-trip Unicode
  через Wayland clipboard: все проверки прошли, завершение скрипта — код 0.
- Использовалась отдельная минимальная среда Python/Qt для портала.
  Этот результат не заменяет нативную проверку всей замороженной сборки в
  GNOME/KDE Wayland. Динамический непрерывный захват проверен на X11.

### macOS

- Нативная машина: macOS 14.3, Apple Silicon arm64, Retina DPR 2,
  Python 3.12.14, Qt 5.15.14, PyQt 5.15.11. Минимум 13.4 проверен по
  фактическим deployment targets всех 228 Mach-O файлов.
- Дополнительно к полному прогону: 194 проверки Cocoa UI и 26 subtests,
  затем 136 платформенных проверок с новым средством подписи и окном разрешений — без падений.
- Расширенный smoke Python-версии и подписанной `.app`: по 463 снимка,
  обе темы, шесть языков, масштабы 80/100/125/150/200%, окна, настройки,
  сворачивание исходного текста, восстановление размеров, трей и Dock.
  Запуск `.app` проверен через `open`/LaunchServices, как при запуске Finder.
- Настоящий Vision распознаёт сгенерированную картинку; упакованный RapidOCR

- Carbon зарегистрировал хоткеи и получил 10 контролируемых событий внутри
  процесса; это не проверка физического глобального сочетания из другой программы.
- Велком отдельно проверен на всех шести языках в двух темах: галочка видна,
  весь текст помещается, меню языков полностью отображается. PNG сохранены.
- У компаньона отключена системная тень Cocoa, создававшая обводку прозрачного
  окна. `WA_MacAlwaysShowToolWindow` сохраняет его на рабочем столе при уходе
  главного окна в трей и переключении в другую программу. Проверка использует
  настоящий NSPanel и список окон Quartz: размеры 60/100/180%, оба состояния
  «Поверх окон», закрытие главного окна, переход в Finder и пересоздание панели.
  Явное скрытие приложения и скрытие на время захвата экрана продолжают работать.
  Нативный прогон компаньона, трея и разрешений: 66 проверок; отдельно 6 снимков
  двух видов компаньона с прозрачными углами. На Windows — 59 связанных проверок.
- Стандартная полоса прокрутки окна разрешений заменена тонкой полосой в цвет
  темы, без стрелок и фоновой дорожки; она видна только при нехватке места.
  Повторно прошли 20 проверок и 24 нативных снимка окна на шести языках,
  в двух темах, при масштабах 100% и 200%.
- Окно новостей после обновления теперь использует тот же `WelcomeDialog`,
  что и первый запуск: есть Telegram, GitHub проекта и текст о бесплатности.

  43 проверки этих окон дополнительно прошли на настоящем Qt Windows.
  После общего оформления полос: 72 нативные проверки на Mac и 66 в X11 Linux.
- При открытии разрешений macOS приложение скрывает свои нативные окна,
  включая окно поверх остальных. Отдельный Cocoa-сценарий подтвердил,
  что System Settings оказывается впереди, на экране не остаётся окон
  тестового процесса, а возврат восстанавливает диалог и уровни окон.
  В этом сценарии системный запрос разрешения имитирован, переход в
  настоящие System Settings и скрытие/восстановление AppKit выполнены реально.
- Пользователь выдал новой подписи Screen Recording. Настоящий захват
  подписанной сборкой прошёл: получено непустое изображение; в отдельных
  запусках Qt сообщил 2560×1600/DPR 2 и 1280×800/DPR 1, значения сохранены в отчётах.

  отправка Cmd+C/V этой сборкой в стороннее приложение ещё не проверена.
  Проверка разрешений сохраняет только размеры, без пикселей экрана и буфера.
- DMG дополнительно проверен `hdiutil verify`, подключён только для чтения;
  встроенная `.app` прошла глубокую проверку подписи. ZIP прошёл CRC-проверку.

  запрос от текущего процесса и открывают нужный раздел macOS, состояния

  внимание; окно появляется при первом показе основного интерфейса.
  После приветствия/новостей оно предшествует обучению. Проверено 20 тестами,
  в нативном Cocoa — 87 связанных проверок и 672 subtests; отдельно 24 снимка
  на шести языках, в двух темах при 100/200%. При большом масштабе пояснения
  прокручиваются, заголовок и нижние кнопки остаются в границах экрана.

### Реальные движки в финальных сборках

- RapidOCR из `OcrWorker`: настоящее распознавание сгенерированного
  `HELLO WORLD`; confidence 0.9611 Windows и 0.9935 Linux.
- `ArgosWorker`: импорт нативных библиотек и проверка отсутствующей пары в
  чистом каталоге; затем настоящее офлайн RU→EN с отдельной копией уже имеющейся
  модели `translate-ru_en-1_9`. Загрузка модели запрещена, HTTP-прокси направлен
  на недоступный loopback; перевод повторён в новом процессе на каждой системе.
  «Привет, мир! Это бесплатное приложение.» → «Hello, world! It's a free app.»
- Google и MyMemory: отдельные настоящие сетевые запросы из Python-версии на
  Windows, только с сгенерированным текстом. Оба вернули корректный непустой
  русский перевод. Это проверка доступности на момент запуска, не оценка всех
  языков или качества больших документов.

## Исправления в ходе проверки

1. **Велком:** добавлено сообщение о бесплатном проекте с приглашением в Telegram
   и просьбой поставить звезду на GitHub на всех шести языках. Кнопка GitHub
   открывает репозиторий проекта. Текст полностью помещается в обеих темах;
   иконки социальных ссылок контрастнее в светлой теме.
2. **Установщик:** исправлен синтаксис `Excludes` и исключены корневые `data`,
   `ocr`, `translators`, `program-files.sha256`. Раньше неверный разделитель мог
   привести к замене пользовательских данных. Формат сверён с
   [документацией Inno Setup](https://jrsoftware.org/ishelp/topic_filessection.htm).
3. **Qt lifetime:** исправлено преждевременное удаление базового стиля при
   уничтожении выпадающих списков/акцентных элементов. На Linux это давало
   segfault. Стиль теперь живёт в отдельном QObject до отложенного удаления;
   добавлены проверки закрытия и полного освобождения.
4. **Linux UI:** исправлены отступы немецких вкладок и французской кнопки темы,
   сокращена французская подпись истории переводов. Проверки размеров учитывают
   допустимое округление Qt до одного пикселя при сохранении одинаковой ширины.
5. **Инфраструктура QA:** нативные Windows-сценарии пишут только в тестовые
   каталоги; актуализирован Linux-сценарий динамического режима и очистка
   временного Wayland mount; экспорт исходников включает C# launcher и публичный
   сертификат Mac, исключает приватные ключи.
6. **Mac/Retina:** уточнены отступы вкладок настроек для дробных метрик Cocoa;
   pixel-тесты учитывают DPR, проверки масок — прозрачный фон на Mac.

7. **Подпись Mac:** добавлен выбор имени отдельной local identity и подпись
   всего вложенного нативного кода без hardened runtime. XML entitlements

Windows, из корня проекта и с установленными зависимостями:

```powershell
.venv\Scripts\python.exe tools/run_regression_tests.py --output .tmp/qa-repeat tests
.venv\Scripts\python.exe tools/qa_windows_fullscreen.py
.venv\Scripts\python.exe tools/qa_windows_live_translation.py
```

Linux, в отдельной среде с Python 3.12 и зависимостями `requirements-linux.txt`:

```bash
python tools/run_regression_tests.py --output .tmp/qa-repeat tests
xvfb-run -a -s '-screen 0 1920x1080x24' python tools/qa_linux_dynamic_output.py
python tools/qa_frozen_workers.py dist/clickntranslate --output .tmp/frozen-repeat
```

Для просмотра полного набора аргументов Wayland-сценария использовать
`tools/qa_linux_wayland.sh`; ему нужны Sway, portal, PipeWire и отдельная сессия
DBus. Снимки окружений Python сохранены в `evidence/`.

## Ограничения

Mac Intel не собран и не проверен. Screen Recording и Accessibility новой
подписи выданы; захват экрана проверен. Автоматическое Cmd+C/V в стороннем
приложении из финальной сборки, чистая установка и полный путь обновления
в этой сессии отдельно не проверялись. Hy-MT, EasyOCR, весь набор
онлайн-провайдеров, реальные игры, аппаратные мультимониторные конфигурации
и длительный нагрузочный прогон не охвачены этой сессией.
В `evidence/` сохранены ранние диагностические логи, включая найденные и
исправленные падения. Актуальные полные прогоны относятся к последним правкам
прокрутки: Windows — `windows-scrollbars-final`, Linux/macOS — прогоны
`scrollbars`. Итоговые числа приведены в таблице выше. Предыдущие прогоны
`startup`, `permissions`, `mac-sync` и `signed` отражают более ранние этапы QA.
