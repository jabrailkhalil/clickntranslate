# Click'n'Translate on Windows

Windows 10/11 x64: choose the installer or extract the complete Portable ZIP.
Python is included. Keep the portable `app` folder beside `ClicknTranslate.exe`.

[Download the current release](https://github.com/jabrailkhalil/clickntranslate/releases/latest).

The current self-signed identity `jabrailkhalil` does not establish public
publisher trust. A guide cannot guarantee that Defender will never flag a
future file. The instructions distinguish SmartScreen from antivirus detections
and explain how to report and handle a verified false positive for the affected
file, while keeping protection enabled.

## Updates and support

Use the Update button in the Windows app. Keep your existing user data.
For an installation failure, record the exact error and version before retrying.
See [update checks and limitations](UPDATE_AUDIT_2026-09-25.md).

[Report a problem](https://github.com/jabrailkhalil/clickntranslate/issues).
For developers: [Windows code signing](WINDOWS_SIGNING.md).
