# Mascot generation prompts

Generated with the built-in imagegen tool on 2026-09-27 for Click'n'Translate 1.8.2. The owner's five character concepts in the reference chat informed this set. The first atlas establishes the style; the four other atlases use it as a visual reference.

Source PNGs are preserved in `sources/`. `python tools/prepare_mascots.py` packages the transparent artwork into ten-frame GIFs and five static poses per character. It detects clear grid gutters, resizes sprites and aligns their feet. Runtime assets are in `src/icons/desktop-assistant/`.
