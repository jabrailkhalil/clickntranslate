# Общий интерфейс и перевод для Windows, Linux и macOS

9 сентября 2026 года. Версия исходников: 1.7.1. **Это передача кода, не релиз.**
Изменения ветки `codex/macos-1.7.1` перенесены в `main`; теги, GitHub Release,
публикация установщиков и автоматическое обновление пользователей не выполнялись.

## Как подтянуть

Если локальная `main` чистая и не содержит собственных коммитов:

```bash
git fetch origin
git switch main
git pull --ff-only origin main
```

Если работа уже идёт в отдельной ветке, сначала сохраните свои изменения коммитом,
затем выполните `git fetch origin` и `git merge origin/main` в своей рабочей ветке.
Конфликты нужно объединять по смыслу. Не применять `reset --hard`, не заменять
пользовательские данные и не копировать отдельный `main.py` без его зависимостей.
Из ветки `codex/shared-hover-tooltips` также следует объединить `origin/main`:
последующая переработка подсказок находится в общем коде.

UI-строки поддерживают RU/EN/ES/DE/FR/ZH. Процент — доля завершённых частей запроса,
не оценка оставшегося времени. Он показывается только для незавершённого запроса
с несколькими частями; для одного блока не появляются ни проценты, ни строка
«Переводится в реальном времени...», включая начало запроса. По завершении
строка главного окна очищается, 100% не остаётся. Выбранные OCR-движок и переводчик обязательны:
ошибка отображается пользователю и не переводит запрос на другого провайдера.

## Платформенные границы

В `main` также сохранён Mac-порт. Cocoa, Carbon, Vision, ScreenCaptureKit,
разрешения, подпись и LaunchAgent вызываются только на Mac; дополнительные
PyObjC-зависимости находятся в `requirements-macos.txt` и Mac-spec.
Windows и Linux используют собственные requirements и сборочные файлы.
Приватные ключи, настройки пользователя, история и загруженные модели в Git
не передавались. Компактная базовая геометрия Mac остаётся платформенной.

На Mac устранено скрытие оверлея на время снимка: кадр получается с исключением
окон приложения. На Windows с доступным display affinity сохраняется системное
исключение из захвата. На Linux и старых Windows остаётся прежнее временное
скрытие для захвата — нельзя считать этот путь полностью свободным от мерцания.

## Проверки отложены

По просьбе пользователя новые pytest, smoke и визуальные прогоны не запускались.
Существующие сценарии приведены к изменённой геометрии и сохранению предыдущего
кадра, но их новый результат неизвестен. Локальная сборка Mac не подтверждает
работу на Windows/Linux. Перед будущим релизом выполнить нативную сборку и QA
на каждой ОС: темы, масштаб, подсказки, списки, отмена/ошибка по частям, раскрытие
во время запроса, выбранные провайдеры и оба динамических режима.
Подробности Mac и границы выполненных ранее проверок: [MACOS_QA.md](MACOS_QA.md).
