# Частная сборка 1.7.1 ux4

Без публикации, push, commit или tag. Предыдущие сборки и данные сохранены.
GUI-проверки выполнялись исключительно через `QT_QPA_PLATFORM=offscreen`,
без окон поверх работы пользователя и без остановки его процессов.

## Приветствие, панели и подсказки

- «Пропустить» получил непрозрачную полноценную область нажатия, минимальный
  размер 104 × 36, указатель и отключённое автоматическое действие Enter.
  При смене языка старый `welcomeCard` теперь сразу скрывается, а затем
  удаляется отложенно: он не должен перехватывать клики в модальном цикле.
  Проверено на 6 языках, в 2 темах и при 100/150/200%: видимость области,
  hit-test, непрозрачность, press/release с обработкой очереди между ними,
  закрытие без запуска обучения. Нативный отказ Windows отдельно
  не воспроизводился: по просьбе пользователя видимые тестовые окна не открывались.
- Верхняя часть главного окна разделена на панель выбора направления и
  две самостоятельные карточки ввода/перевода. Общая внешняя рамка удалена.
  Проверки контраста границ теперь относятся к новым карточкам, а не к
  ставшему прозрачным контейнеру. Поля, разворот и копирование сохранены.
- Самолётик остаётся без рамки, включая отключённое состояние. Ранее общая
  тема `quiet` добавляла рамку именно отключённой кнопке.
- Выполнен `git fetch origin`, просмотрена актуальная ветка macOS
  `origin/codex/macos-1.7.1` (97d3e74), в частности 149777b и 11abea2.
  Их основной код подсказок уже присутствовал; слепого слияния не было.
- Frameless-флаг прозрачных подсказок раньше выставлялся только на macOS.
  Теперь он устанавливается и на Windows до создания нативного окна.
  При перерисовке очищается старый alpha-фон, маска Windows сохранена.
  Это соответствует требованиям
  [Qt к прозрачным окнам](https://doc.qt.io/archives/qt-5.15/qwidget.html#creating-translucent-windows).
  Проверены прозрачные углы светлой подсказки и повторное использование
  одного окна с длинным/коротким текстом, а также смена темы.

## Маскот

- Новый оригинальный круглый фиолетовый значок, сгенерированный встроенным
  imagegen. [PNG](../src/icons/desktop-assistant/purple-orb.png),
  [полный промпт и происхождение](MASCOT_PURPLE_ORB_PROMPT.md).
  Выходной RGBA-файл скопирован без изменений; прозрачность проверена.
- Статичные варианты: мордочка, обычный Кирби, Кирби на звезде, сонный Кирби,
  собственное изображение. Таймер движения у них не работает.
- «Гуляет» — отдельный пиксельный Kirby. В выборе показан тот же спрайт,
  что на рабочем столе. Только ходьба и пауза; во время паузы сохраняется
  текущий кадр, без подмены на другой 3D-рисунок. Сон, оглядывание и прыжок
  больше не смешиваются с ходьбой. Наведение, перетаскивание, меню и захват
  приостанавливают движение; захват скрывает маскота.
- Настройки прогулки видны только для гуляющего Кирби; для статичных
  значков есть пояснение. Размер, непрозрачность, поверх окон и возврат
  на своё место доступны всем включённым вариантам.
- Старое `animated/walk` переходит в `walking`; `animated/sleep` — в
  статичный сонный вариант; прежние искусственные idle/look — в мордочку.
  Явно выбранные статичные картинки сохранены.
- Сторонние Kirby-ресурсы остаются только в частной сборке; сведения
  об их происхождении и ограничениях сохранены в README рядом с картинками.
