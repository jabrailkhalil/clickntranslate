# Youdao text adapter

Independent HTTP integration, not a vendor SDK/runtime import. Provider selection is explicit. Fixed destination: `https://openapi.youdao.com/api`; opening settings, saving credentials and choosing a domain do not translate or upload text.

The application ID and application secret are one versioned, service-bound encrypted vault value. They never enter AppSettings, profiles or settings exports. A raw old key or partial pair is rejected. There is no automatic migration from earlier shared OCR/photo credentials. New input is masked, not restored after recreation, and displayed in a secure window. Domain is public configuration and participates in capture invalidation, photo work identity and both translation cache levels.

The v3 signature uses an independent implementation of the documented Java UTF-16 input convention. Original text must contain valid Unicode. If official Java truncation splits a surrogate at the signature boundary, Java/Android UTF-8 encodes its replacement as byte `3f`; pinned vectors test this. The official Python3 example uses code points and differs for supplementary characters. No automatic retry with another convention is performed. **Real server acceptance of these emoji edge cases remains unverified.**

App limits:4000 UTF-8 bytes per request,65536 encoded form bytes,131072 response bytes,65536 translated bytes,128 returned parts, JSON depth12. These are app bounds, not a statement of account quota. Signed UUID/time are created after cancellable in-flight gate ownership; one of32 fixed gates avoids an unbounded account map. Shared one-shot POST policy prevents the HTTP library from resubmitting a potentially billable request after503/Retry-After:0. A new explicit translation is a new request.

General translation supports the reviewed language subset and exact Simplified/Traditional aliases. Common catalogue117 does not imply117 reviewed Youdao codes. Specialized domains (`computers`, `medicine`, `finance`, `game`) require the reviewed English ↔ Simplified Chinese pair and account access. They send `rejectFallback=true`; a response without the documented domain-support confirmation is refused. Provider error messages, returned dictionaries, audio and links are not displayed or followed. Typed clock/replay/credential-pair guidance is available in all six interface locales and persisted photo errors retain that classification.

This adapter translates text after the app's independently selected OCR. It does not implement the former provider-specific picture-translation endpoint; differences stay visible in the parity journal. Account entitlement, billing, live translation/domain quality and emoji interoperability have not been tested with a paid account.
