常见问题

安装之前。

可以离线使用吗？

可以。你需要先安装 OCR 语言数据，以及所需翻译方向的 Argos Translate 或 Hy-MT 语言包。在线服务商仍然需要网络连接。

可以翻译游戏和视频吗？

可以。OCR 读取所选区域的像素，因此原文无需能够选中。准确度取决于语言、字体、缩放、对比度和所选 OCR 引擎。

支持 Linux 吗？

支持。版本页面提供 x86_64 AppImage 和便携式 TAR 压缩包。屏幕捕获集成可能因桌面会话而异。

可以修改所有快捷键吗？

可以。每个全局快捷键都能修改或清除。OCR、全屏、选中、替换和动态翻译模式会分别记住各自的语言对。

支持哪些文档格式？

支持 TXT、Markdown、DOCX、PDF、HTML、HTM 和 RTF。结果可保存为文本、Markdown，或可重新打开的本地会话。
