FAQ

你可能还想知道。

可以离线使用吗？+

可以。请先下载识别语言和 Argos Translate 或 Hy-MT 模型。在线翻译服务仍然需要网络。

如何更新？+

Windows 可使用应用内的更新按钮。Mac 和 Linux 请下载新的 DMG 或 AppImage 并替换应用，保留原有用户数据。

所有游戏都支持吗？+

可以识别游戏和视频中可见的文字。字体、图像质量和截图限制会影响效果，有时需要窗口模式。

可以修改快捷键吗？+

可以在设置中修改。Mac 使用 Command 和 Option 对应 Ctrl 和 Alt；Linux 请在桌面环境中配置快捷键。

支持文档吗？Mac 需要哪些权限？+

支持 TXT、Markdown、DOCX、PDF、HTML 和 RTF。Mac 应用会引导你开启屏幕录制和辅助功能权限。
