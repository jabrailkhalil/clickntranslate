# План актуализации и следующего обновления Click’n’Translate

Состояние на **25 октября 2026 года**: опубликована **1.8.2** для Windows,
macOS, Linux и Android. Следующее обновление планируется примерно через две
недели. Номер, точная дата и итоговый состав ещё не объявлены.

## Сейчас: привести существующие страницы к одному состоянию

1. Сверить [журнал размещений](../PROMOTION_LOG.md): финальный URL и статус важнее
   старого черновика. Запись «отправлено на модерацию» не означает «опубликовано».
2. Выполнено 25 октября: в DEV сохранены актуальные ссылки и список платформ,
   в Open Hub — новое описание и ссылка на сайт. Правки существующей карточки
   AlternativeTo с Mac/Android и двумя снимками 1.8.2 отправлены на модерацию.
   Их одобрение пока не подтверждено.
3. Сохранить исторический рассказ старых статей. В DEV актуальные платформы и
   ссылки добавлены в заключение; прежние измерения не выдаются за результаты
   новой версии. Новая рекламная статья не публиковалась.
4. Карточка [AlternativeTo](https://alternativeto.net/software/click-n-translate/about/)
   опубликована 5 сентября и проверена 25 октября: редактируем её из аккаунта

   не имела подтверждения принятия по аудиту 22 октября. Не создавать повторные заявки.
5. Проверить владельца аккаунта перед любой записью. Для GitHub использовать
   только `jabrailkhalil`.
6. В будущих материалах использовать факты из [press-kit.md](press-kit.md) и
   [positioning.md](positioning.md). Возможности платформ отличаются.

## До обновления: подготовка без преждевременного анонса

- Сделать короткий список изменений из готового кода и воспроизводимых проверок.
- Выбрать реальные desktop/Android снимки и записи, убрать частные данные.
- Проверить текущие требования площадок из `platform-rules.md`.
- Проверить результат модерации правок AlternativeTo, не отправляя дубликат.
  Права владельца на AlternativeTo, DEV и Open Hub уже подтверждены. Статусы сверять с
  [реестром размещений](../PROMOTION_LOG.md).
- Подготовить один пользовательский пост и один технический материал.
- При желании подготовить WinGet-метаданные; создавать manifest только для
  неизменяемого опубликованного файла с заново проверенным хешем.
- Product Hunt и Show HN подготовить отдельно, с доступным продуктом и временем
  на ответы. Черновик Хабра — справочный материал с использованием ИИ, не текст
  для публикации. Нужна самостоятельная техническая статья автора с его опытом;
  лёгкая переработка этого черновика не отвечает текущим правилам.
  См. [platform-rules.md](platform-rules.md#habr).

## Когда обновление действительно выйдет

| Шаг | Действие |
| --- | --- |
| День выпуска | Сверить опубликованные файлы, обновить существующие карточки и страницы |
| После проверки загрузок | Опубликовать один основной анонс со ссылкой на сайт и списком готовых изменений |
| Следующие дни | Разнести разные материалы по подходящим площадкам, соблюдая их правила |
| Отдельный выбранный день | Product Hunt / Show HN, если комплект готов и автор сможет отвечать |
| Через 2–4 недели | Сопоставить переходы, загрузки по платформам и содержательные отзывы |

Не копировать один рекламный текст в несколько сообществ подряд. Не просить
организованные голосования. Отвечать на воспроизводимые проблемы и сохранять
обсуждения в соответствующих темах.

## Материалы для разных аудиторий

| Аудитория | Сценарий | Подходящее доказательство |
| --- | --- | --- |
| Игроки и читатели | Переводить диалог, не покидая игру | Запись выбранной области или мобильной плавающей кнопки |
| Изучающие язык | Сравнивать оригинал с переводом | Реальный результат и копирование оригинала |
| Desktop power users | OCR, выделение и замена текста | Короткая запись горячей клавиши или меню маскота |
| Android | Экран, фото, текст и «Поделиться» | Снимки текущего мобильного приложения |
| Open source | Архитектура, пакеты и ограничения | Код, датированные проверки, воспроизводимый пример |
| Офлайн-сценарии | Использовать установленную модель | Явно выбранный локальный движок и поддерживаемая пара |

## Ссылки и измерение результата

Базовая ссылка: https://translate.clickn.dev/. Для различения площадок допустимы
агрегированные UTM-метки, например
`?utm_source=devto&utm_medium=article&utm_campaign=clickntranslate_2026_11`.
Не включать в них имена, email, тексты сообщений или идентификаторы пользователей.
Политика сайта: https://clickn.dev/en/privacy/. Не смешивать её с политикой
настольного приложения.

Записывать подтверждённые URL и даты в журнал. Сравнивать переходы по источникам,
загрузки по платформам и качество обратной связи. Не публиковать неподтверждённые
цифры тестов, аудитории и производительности.

## Ограничения формулировок

- Публикация новой версии остаётся отдельным действием; этот план её не выполняет.
- Не обещать дату и функции ещё не выпущенного обновления.
- Не называть текущие desktop-сборки неподписанными: используется самоподписанная
  идентичность `jabrailkhalil`, без публично доверенного Windows CA / Apple Developer ID.
- Не обещать локальность при выбранном сетевом или image API.
- Не заявлять, что все 63 языка поддерживаются каждым OCR и переводчиком.
