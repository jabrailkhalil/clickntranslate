# Click'n'Translate product demo

## Goal

Create a compact README and launch-page demo that explains the product without narration.

## Audience

People who encounter foreign text in games, images, videos, desktop apps, and messages.

## Promise

Translate text anywhere on the screen, or replace selected text with its translation, while staying in the current workflow.

## Format

- Duration: 12 seconds
- Resolution: 1920 × 1080
- Language: English
- Sound: none required
- Style: dark desktop UI, restrained purple accent, premium but practical

## Required claims

- Windows and Linux
- Free forever
- Open source
- No account
- 1,000+ downloads

## Product truth constraints

- Dynamic mode translates user-selected screen regions, not the entire screen.
- Text replacement starts from explicitly selected text.
- Do not imply cloud privacy guarantees or completely offline translation.
