# Передача macOS-версии следующему агенту

Подготовлено 6 сентября 2026 года. Версия приложения — **1.7.1**.

Обновление после передачи: нативная сборка arm64 и установка из DMG выполнены
на Mac. Актуальные результаты, исправления и оставшиеся ручные проверки находятся
в [MACOS_QA.md](MACOS_QA.md). Описание ниже сохраняет исходное состояние передачи;
минимальная версия уточнена до 13.4 по фактическим библиотекам ONNX Runtime.

## Задача

На настоящем Mac запустить Python-версию, проверить перенос, исправить найденные
ошибки и собрать `.app`, `.dmg` и `.zip`. Пользователь попросил максимально
подготовить работу на Windows; нативное тестирование и сборку выполнит агент на Mac.

**Сборка на Mac ещё не выполнялась.** В этой передаче нет готового Mac-приложения.
Есть реализация, проверенные на Windows/Linux общие части, сценарии нативной
проверки и сборки. Не считать успешные тесты с имитацией платформы доказательством
работы Carbon, Vision, Cocoa, Accessibility или Retina на настоящем Mac.

Обязательное требование пользователя: **выбранным движком и выполнять операцию**.
Это относится и к OCR, и к переводчику, включая область, весь экран, динамический
перевод и документы. Ошибку выбранного движка нужно показать; автоматически
отправлять текст другому провайдеру или переходить на Argos запрещено.

## Какие исходники использовать

Основной способ передачи — ветка **`codex/macos-1.7.1`** репозитория
`https://github.com/jabrailkhalil/clickntranslate`. Она включает изменения
программы 1.7.1, общие модули UI, Mac-перенос, тесты и сборочные инструкции.
Основная ветка `main` может ещё не содержать этот перенос. В новом каталоге:

```bash
git clone --branch codex/macos-1.7.1 https://github.com/jabrailkhalil/clickntranslate.git
cd clickntranslate
git status --short
git log -1 --oneline
```

Если проект уже открыт и в нём есть работа другого агента, сначала сохранить
её и выбрать отдельную ветку/рабочий каталог; не сбрасывать изменения командой
`reset --hard`. Результаты предыдущих локальных тестов не означают, что нативный
GitHub Actions уже прошёл: его состояние проверять отдельно.

Альтернативный способ — ранее подготовленный архив
`Click-n-Translate-1.7.1-macos-source.zip`. Для работы через GitHub он не нужен.

Архив содержит исходники приложения, иконки, тесты, документы и сборочные файлы;
в нём нет `.git`, виртуальных окружений, пользовательских настроек, историй,
скачанных моделей, сертификатов и маркетинговых проектов. Содержимое корня архива
нужно распаковать в отдельный каталог проекта. Не подменять им каталог с другой
незавершённой работой. `HANDOFF_MANIFEST.json` содержит SHA-256 каждого файла и
исходный Git commit; содержимое включает изменения поверх этого commit.

До распаковки, из каталога с архивом и соседним файлом контрольной суммы:

```bash
shasum -a 256 -c Click-n-Translate-1.7.1-macos-source.zip.sha256
```

После распаковки можно дополнительно проверить содержимое самого архива:

```bash
python3 tools/prepare_macos_handoff.py --verify /absolute/path/Click-n-Translate-1.7.1-macos-source.zip
```

## Запуск и проверки

Поддерживаемая цель — macOS 13.4+, Python 3.12, отдельные сборки Apple Silicon
(`arm64`) и Intel (`x86_64`). Использовать Python нужной архитектуры; на Apple
Silicon запускать нативный терминал и Python, без случайного перехода в Rosetta.

Из корня проекта:

```bash
sw_vers
uname -m
python3.12 -c 'import platform, sys; print(sys.version); print(platform.machine())'
bash tools/setup_macos_env.sh
mkdir -p build/macos
.venv-macos/bin/python -m pip freeze > build/macos/environment.txt
```

Если Python 3.12 отсутствует, установить его обычным способом; при наличии
Homebrew: `brew install python@3.12`. Затем повторить setup. Скрипты запускаются
через `bash`; права исполняемого файла после переноса не обязательны.

Сначала выполнить набор, который используется в нативном CI:

```bash
set -o pipefail
QT_QPA_PLATFORM=offscreen .venv-macos/bin/python -m pytest -q tests/test_macos_support.py tests/test_translation_chunks.py tests/test_ocr_text_layout.py tests/test_document_services.py tests/test_single_instance.py 2>&1 | tee build/macos/targeted-tests.log
```

Затем запустить весь набор для поиска дополнительных проблем переноса:

```bash
QT_QPA_PLATFORM=offscreen .venv-macos/bin/python -m pytest -q 2>&1 | tee build/macos/all-tests.log
```

Разбирать каждое падение. В прежних тестах могут оставаться предположения о
Windows или Linux; платформенную границу исправлять по смыслу, не отключать
проверки общей логики ради зелёного результата. Нативный тест каталога Vision
на Mac должен выполняться, а не пропускаться.

Запустить настоящий интерфейс Cocoa, без переменной `QT_QPA_PLATFORM=offscreen`:

```bash
.venv-macos/bin/python main.py
```

Обычный запуск использует реальные пользовательские настройки. Автоматический
smoke-тест сборки использует временные настройки и не запрашивает доступ к экрану
или управление другими приложениями. Он не заменяет ручную проверку разрешений.

## Что реализовано и где смотреть

| Область | Основные файлы |
| --- | --- |
| Vision OCR, языки и координаты | `macos_ocr.py`, `ocr.py`, `ocr_text_layout.py` |
| Регистрация горячих клавиш Carbon | `macos_hotkeys.py`, `main.py` |
| Разрешения, Cmd+C/V, фокус, Dock, автозапуск | `macos_desktop.py`, `macos_text.py`, `main.py` |
| Второй экземпляр и проверка PID | `single_instance.py`, `instance_lifecycle.py` |
| Геометрия и отслеживание динамического перевода | `game_mode.py`, `ocr.py` |
| Каталоги данных, системные команды, Homebrew | `platform_support.py`, `portable_paths.py` |
| Установка и удаление OCR-пакетов | `settings_window.py`, `ocr_worker.py` |
| Строго выбранный переводчик, дробление и отмена | `translater.py`, `translation_chunks.py`, `document_translation.py` |
| Сборка и встроенные проверки | `ClicknTranslate-macos.spec`, `tools/build_macos_release.sh`, `macos_smoke.py`, `tools/smoke_macos_bundle.py` |

При импорте настроек с недоступным Windows OCR выбор мигрирует в видимый
Apple Vision до создания интерфейса. Выбор доступного движка сохраняется.
Список языков Vision зависит от установленной macOS; неподдерживаемый язык
не должен незаметно превращаться в другой язык или движок.

Qt PortableText на Mac трактует `Ctrl` как Command, а `Meta` как физический
Control. Регистрация Carbon следует этой же схеме; интерфейс показывает
нативные обозначения. Не менять это только из-за названия поля в JSON.

RapidOCR включён в отдельный `OcrWorker`; Argos использует `ArgosWorker`.
EasyOCR устанавливается отдельно через совместимый Python 3.12. Для Intel
закреплены PyTorch 2.2.2 / torchvision 0.17.2; другой архитектуре нельзя отдавать
эти колёса. Tesseract доступен через Homebrew. Windows-инсталляторы на Mac
заблокированы. Автоматического Mac-инсталлятора Hy-MT нет: нужен совместимый
llama.cpp и модель, см. `docs/MACOS.md`.

## Обязательная проверка на настоящем Mac

Проверить Python-запуск, затем повторить основные сценарии на приложении,
скопированном из DMG в `/Applications`. Для разрешений эти запуски могут иметь
разные идентификаторы в System Settings.

1. **Разрешения.** Чистый запуск не вызывает системных запросов. Отказ в Screen
   Recording и Accessibility корректно останавливает соответствующее действие.
   Кнопка в нашем диалоге открывает нужный раздел настроек; после выдачи доступа
   и необходимого перезапуска действие работает. Python может отображаться
   как Python/Terminal. Не отключать TCC или Gatekeeper ради прохождения теста.
2. **Горячие клавиши.** Настоящие нажатия при другом активном приложении, RU/EN
   раскладки, удержание, смена сочетания, конфликт, очистка и повторная
   регистрация после открытия настроек. Проверить физическую ISO-клавиатуру,
   если доступна: текущая таблица основных клавиш основана на ANSI-позициях.
3. **Выделенный текст.** Перевод и замена в TextEdit и браузере. Во время запроса
   сменить окно/выделение, подержать модификаторы, отменить операцию: перевод
   не должен вставиться в чужое окно. Защищённые поля не обязаны позволять копирование.
4. **OCR и Retina.** Каждый установленный движок отдельно; область, весь экран,
   несколько областей динамического перевода. Проверить экран Retina и внешний
   монитор с другим DPI, монитор слева от основного, Spaces и полноэкранное
   приложение. Координаты должны совпадать с текстом, без размытия и обрезания.
5. **Динамический перевод.** Перемещение, сворачивание и закрытие целевого окна;
   переключение фокуса. Переведённый оверлей не должен повторно попадать в OCR.
   Отдельно оценить мерцание при скрытии оверлея на время захвата.
6. **UI.** Обе темы, несколько повторных переключений, RU/EN и длинные подписи
   остальных языков; главное окно, все страницы настроек, документы, результат,
   справка и гайд. Масштабы 80/100/125/150/200% с учётом размера экрана: чёткие
   шрифты/иконки, читаемые списки и подсказки, доступные кнопки. Трей и OCR-области
   не должны увеличиваться вместе с окнами. Сохранить скриншоты Cocoa.
7. **Переводчики и пакеты.** Перевод небольшого и длинного тестового текста каждым
   доступным провайдером; ошибка сети не меняет провайдера. Установить, отменить
   установку, удалить и переустановить тестовую языковую пару Argos и доступный
   OCR-пакет. Проверить офлайн-перевод после перезапуска. Системные модели
   Homebrew не удалять; скачанные файлы не должны попадать внутрь `.app`.
8. **Документы.** TXT/DOCX/PDF, длинный абзац, несколько языков, отмена и частичный
   результат, сохранение и повторное открытие. Проверить вставку дополнительного
   текста и масштабирование окна результата.
9. **Жизненный цикл.** Второй запуск предлагает показать/закрыть прежний экземпляр
   в нашем стиле; перезапуск не теряет конфигурацию. Dock возвращает скрытое
   главное окно и не мешает OCR. Включить автозапуск после установки приложения
   в `/Applications`, проверить следующий вход, затем выключить и проверить
   удаление только нашего LaunchAgent. Не включать автозапуск копии из DMG.

Папка данных: `~/Library/Application Support/ClicknTranslate/`.
LaunchAgent: `~/Library/LaunchAgents/io.github.jabrailkhalil.clickntranslate.plist`.
Не удалять пользовательские данные для «исправления» тестов.

## Сборка и передача результата

```bash
set -o pipefail
bash tools/build_macos_release.sh 2>&1 | tee build/macos/build.log
```

Скрипт проверяет подписи и три Python-архива, запускает настоящий Cocoa GUI,
снимает обе темы главного окна/настроек при 100/150%, распознаёт тестовый текст
через Vision и RapidOCR, регистрирует/снимает Carbon-хоткей и проверяет Argos helper.
Доставка реального нажатия клавиши и перевод реальной Argos-моделью проверяются
вручную. Результаты — `build/macos/smoke.json` и `build/macos/smoke*.png`.

Артефакты: `dist/ClicknTranslate.app`,
`releases/Click-n-Translate-1.7.1-macos-<arch>.dmg`, `.zip` и `.sha256`.
Для второй архитектуры нужна её нативная сборка или соответствующая задача
`.github/workflows/macos.yml`. Не помечать обе архитектуры проверенными по
результату одного Mac; отдельно указать непроверенные версии macOS/мониторы.

Без настроенного Apple Developer ID и нотариализации получается сборка для
разработки. Если подходящая identity и keychain profile уже настроены, скрипт
использует `MACOS_CODESIGN_IDENTITY` и `MACOS_NOTARY_PROFILE`. Одобрение SignPath
для Windows не заменяет подпись Apple. Не публиковать такую сборку как доверенную
пользовательскую версию без соответствующей проверки.

После исправлений повторить затронутые тесты, нативный smoke и ручные сценарии;
сохранить логи, версии зависимостей, скриншоты и краткий отчёт в
`docs/MACOS_QA.md`. В отчёте разделить пройденные, не пройденные и не выполненные
проверки; дать ссылки на полученные артефакты и указать статус подписи.
