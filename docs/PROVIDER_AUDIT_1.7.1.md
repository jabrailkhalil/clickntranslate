Дата: 6 сентября 2026 года. Проверены Python-версия на Windows и тестовое окружение Ubuntu 22.04 / Python 3.10. Сетевые проверки использовали только подготовленные тестовые фразы. Установка и удаление тестовых пакетов выполнялись во временных каталогах.

## Изменения установки и удаления

- Общий установщик сначала полностью переносит новый движок во временный каталог на целевом диске. Затем заменяет установленный каталог и проверяет результат. Ошибка проверки или отмена возвращает прежнюю установку. При неудаче самого восстановления резервные файлы сохраняются, а сообщение содержит путь к ним.
- Обновление Tesseract сохраняет дополнительные файлы `tessdata`; EasyOCR — `models` и `user_network`. Новые файлы из дистрибутива имеют приоритет над одноимёнными старыми файлами.
- Докачка проверяет начало и полный размер `Content-Range`, передаёт `If-Range` при наличии валидатора и запрашивает несжатые байты. Некорректный диапазон или HTTP 416 приводит к повторной загрузке с начала. Старый конечный файл сохраняется до успешного окончания загрузки.
- Архив Tesseract проверяется по SHA-256 из опубликованного релиза. Контрольные суммы Hy-MT и llama.cpp сопоставлены с метаданными их источников. URL модели Hy-MT закреплён на ревизии `265b2e615a7dc9b06c435dc878829ad99a512ba2`.
- Фиксированный набор зависимостей EasyOCR теперь применяется и к Python 3.12, который использует встроенный Windows-загрузчик. Проверено разрешение именно этого набора. Для Python 3.10 сохраняется подбор совместимых бинарных пакетов; неподтверждённые будущие версии Python не получают старый набор принудительно.
- Перед удалением общего пакета EasyOCR диалог показывает остальные затронутые языки. После частичного удаления или отмены сбрасываются загруженные объекты распознавания.
- Системные модели Tesseract на Linux отображаются в менеджере. Их удаление направляет пользователя к пакетному менеджеру дистрибутива; приложение удаляет собственные скачанные модели.
- Результат резервного переводчика сохраняется в кэше под фактически использованным движком. Ответ Argos больше не записывается как ответ Google.

## Внешние API и ограничения

Google подключён через публичные адреса веб-переводчика. Это отдельная интеграция от документированного Cloud Translation API с авторизацией. Переход на Cloud API требует отдельной настройки учётных данных. [Официальный Cloud Translation API](https://docs.cloud.google.com/translate/docs/reference/rest/v2/translate).

Lingva предоставляет REST и GraphQL, что соответствует используемым запросам. Доступность конкретных публичных экземпляров зависит от их операторов. [Документация Lingva](https://github.com/thedaviddelta/lingva-translate#public-apis).

LibreTranslate по умолчанию использует `https://translate.disroot.org`. Для собственного сервера можно задать `CLICKNTRANSLATE_LIBRETRANSLATE_URL` — базовый адрес без `/translate`. Ключ задаётся через `CLICKNTRANSLATE_LIBRETRANSLATE_API_KEY`. Если указан только ключ, выбирается `https://libretranslate.com`. Ключ не добавляется в конфигурационный файл приложения и не передаётся запасным серверам. Управляемый сервис LibreTranslate требует API-ключ. [Документация сервиса](https://docs.libretranslate.com/), [формат API](https://docs.libretranslate.com/guides/api_usage/).

Проверка Hy-MT подтверждает доступность артефактов и поведение кода, но не качество и скорость реальной генерации на компьютере пользователя. Автоматический установщик Hy-MT по-прежнему предназначен для Windows x64; Linux использует отдельно установленный совместимый llama.cpp и GGUF. [Модель и шаблоны запросов](https://github.com/tencent-hunyuan/HY-MT), [метаданные модели](https://huggingface.co/tencent/HY-MT1.5-1.8B-GGUF/tree/265b2e615a7dc9b06c435dc878829ad99a512ba2), [llama.cpp b9048](https://github.com/ggml-org/llama.cpp/releases/tag/b9048).

CRC пакетов Argos проверяет целостность архива и не заменяет криптографическую подпись. Для языковых файлов Tesseract проверяются завершённость и ненулевой размер загрузки; отдельные закреплённые SHA-256 для всех языковых моделей не добавлялись. Контрольная сумма закреплена для самого Windows-дистрибутива Tesseract. [Исходный релиз дистрибутива](https://github.com/jabrailkhalil/clickntranslate/releases/tag/v1.3.2).

## Проверки

- Основной прогон Windows: **405 тестов и 147 подтестов**, без ошибок.
- Основной прогон Linux: **185 тестов и 6 подтестов**, без ошибок; 9 проверок Windows пропущены по платформе.
- После последних изменений маршрутизации LibreTranslate и удаления версий Argos выполнен дополнительный прогон: **112 тестов и 6 подтестов на Windows**, **83 теста и 6 подтестов на Linux**, без ошибок. Эти результаты частично пересекаются с основным прогоном и не суммируются с ним.
- Регрессии покрывают обрыв/докачку, неправильный диапазон, отмену, сохранение старого файла, неудачную установку и восстановление, сохранение языковых моделей, повреждённый архив, частичные операции Argos, общие модели EasyOCR и пути Tesseract в Linux.
- Настоящий цикл EasyOCR загрузил `craft_mlt_25k.pth` (83 152 330 байт) и `english_g2.pth` (15 143 997 байт), распознал картинку и удалил языковой пакет. Временный каталог после проверки очищен.
- Верхняя панель проверена в светлой и тёмной темах, на главной странице и в настройках, при 100% и 160%. Значок документа оптически уменьшен, толщина контура и размеры кнопок сохранены.

В этом проходе не собирались и не публиковались Windows/Linux-дистрибутивы. Проверки относятся к исходной Python-версии и изолированным сценариям установщиков.
