интерфейса и Linux-запуска. Релиз не опубликован; Windows-сборка пока без подписи.

Пропуски полного набора связаны с другой платформой. Inno Setup также был
пропущен внутри изолированного Windows-прогона: его каталог установки скрывался
переопределением LOCALAPPDATA. Этот тест отдельно выполнен с настоящим компилятором.
Два предупреждения Windows исходят от устаревающих SWIG-типов сторонних библиотек.

Набор покрывает сохранение настроек, языковые пары, навигацию, 28 шагов гида,
кнопки и клавиатурный фокус, раскрытие многострочного ввода, документы, истории,
обработку OCR, динамический перевод, горячие клавиши на уровне приложения,
автозапуск, single-instance, обновление, восстановление и ограничения подписи.
Часть интеграций ОС и сетевых отказов проверяется с подменами и временными файлами.

Для UI подготовлены 144 снимка: шесть языков × две темы × главное окно и три
вкладки × три масштаба. Геометрия и текст проверены автоматически; выборочные
снимки просмотрены визуально, включая русский, немецкий и китайский интерфейс.
Окно сохраняет логический размер 700 × 400. В тестовом окружении зарегистрированы
настоящие обычные и полужирные шрифты Windows, включая китайские.

## Найдено и исправлено

1. **Неверная контрольная сумма в утилите восстановления.** Подготовленный URL
   версии 1.7.1 сочетался с SHA-256 предыдущего архива. Теперь URL следует версии,
   а сборка требует явно передать хеш окончательного ZIP. Отсутствующий хеш и
   незащищённый HTTP отклоняются до компиляции. Проверены восстановление из
   локального ZIP и сохранение старой установки при неверной сумме.
2. **Гонка при перегрузке Linux IPC.** Сервер мог отправить BUSY и закрыть сокет
   раньше записи клиента. Клиент теперь считывает уже пришедший ответ после
   BrokenPipe/ConnectionReset, не переподключается и не повторяет команду.
3. **Длинный ввод MyMemory.** Реальный запрос длиной 644 байта отклонялся.
   Добавлено разбиение по установленному API пределу с сохранением разделителей
   и целых Unicode-символов. Проверены кириллица, китайский текст, emoji, длинное
   слово и ошибка на следующем фрагменте. Предел описан в
   [спецификации MyMemory](https://mymemory.translated.net/doc/spec.php).
4. **Пути и URL в Lingva.** Строка с `/home/user` возвращала Not Found; одного
   кодирования `%2F` оказалось недостаточно на проверенном сервере. Для текста
   с `/` используется официальный GraphQL API с JSON-переменными. Остальные
   запросы продолжают использовать REST; проверен переход к следующему серверу
   при ошибке GraphQL. Оба API описаны в
   [репозитории Lingva](https://github.com/thedaviddelta/lingva-translate#public-apis).
5. **Порядок слов OCR.** Простая сортировка по верхней координате переставляла
   `Screen` после `translation test 12345` из-за разницы в один пиксель.
   Общая обработка GUI и worker теперь сначала определяет строки, затем порядок
   слов внутри строки. Слова одной строки соединяются пробелами.
6. **Бледные границы светлой темы.** Немного усилен цвет контуров основных зон:
   они проходят проверку видимости и при дробном масштабировании.

Также обновлены два устаревших теста гида под текущий порядок 28 шагов и реальную
карточку подсказки. Добавлены регрессионные проверки исправленных ошибок.

## Настоящие движки

Использованы специально составленные фразы и изображения, без пользовательского
текста. Сетевые проверки показывают доступность в момент запуска.

| Движок | Наблюдение |
| --- | --- |
| Google | Английский → русский: перевод получен |
| MyMemory | Короткая фраза и длинные английский/русский тексты: перевод получен после исправления |
| Lingva | Обычная фраза и текст с `/home/user`: перевод получен после исправления |
| LibreTranslate | Перевод не получен: первый сервер недоступен в проверке, запасной требует API key |
| Argos, собранные Windows/Linux workers | Настоящий перевод EN → RU и RU → EN на установленных моделях; установка отключена, HTTP-прокси направлен на закрытый локальный порт |
| Windows OCR | Русский и английский тестовые изображения распознаны |
| Tesseract в Linux | Русский и английский тестовые изображения распознаны |
| RapidOCR, Python и собранные workers | Общий образец Arial распознан на обеих ОС; порядок слов дополнительного образца DejaVu исправлен |

RapidOCR на образце DejaVu распознаёт `world` как `oworld` на обеих ОС. Это
оставшаяся ошибка распознавания модели; сортировка текста её не скрывает.
На том же образце Tesseract возвращает правильное слово. OCR не проверен на всех
шрифтах, языках и изображениях; точность каждого распознавания не гарантируется.

## Границы проверки и дальнейший выпуск

- Настоящий ручной сценарий управления окнами Windows не завершён: инструмент
  захвата/ввода возвращал ошибки Windows Graphics Capture и UI Automation.
  Запуск приложения проверен; взаимодействия внутри Qt проверены через QTest.
- WSL не заменяет испытания на отдельном рабочем столе Linux с X11/Wayland.
  Глобальные сочетания, системный трей, выделение в чужих программах, несколько
  мониторов и полный игровой сценарий требуют такой проверки.
- EasyOCR и HY-MT покрыты автоматическими проверками интеграции, но их большие
  модели не загружались для реального распознавания/перевода в этом прогоне.
  Tesseract для Windows не установлен; реальная проверка выполнена в Linux.
- Linux ELF-файлы собраны и запущены; новая AppImage не упаковывалась.
  Финальный подписанный Windows-инсталлятор и обновление с публичного сервера
  1.7.0 → 1.7.1 проверяются после получения доступа к подписи и подготовки файлов.
- Нет нового заключения антивирусов. Подписание и проверка окончательных хешей
  выполняются по [WINDOWS_SIGNING.md](WINDOWS_SIGNING.md).

Локальные логи, JUnit XML, изображения и скрипты воспроизведения лежат в
`.tmp/qa-1.7.1/` и не включаются в репозиторий. Windows stage находится в
`releases/ClicknTranslate-v1.7.1-win64-stage/`; Linux test build — в
`/tmp/cnt-qa-171-build/dist/clickntranslate` внутри WSL. Новые сборки включают
исправления этого прогона. Изменения не закоммичены и не отправлены на GitHub.
