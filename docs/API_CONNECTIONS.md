# Подключения API в десктопной версии

В «Основных настройках» находятся запуск, история, подсказки, обновления, показ окна результата, масштаб и размер текста с примером. Во вкладке «Перевод и OCR» — движки, копирование, замена выделения, закрытие результата и сразу видимые параметры захвата. Чтобы настроить сервис с ключом, откройте **Языковые пакеты → API**.

Доступны OpenAI (Responses API), OpenAI-совместимый сервер (Chat Completions), Gemini, Claude и DeepL API. Ключ LibreTranslate также можно задать в этом окне. Для нейросетевого сервиса укажите точный ID доступной вам модели. Для собственного сервера задайте базовый адрес API, например `http://localhost:11434/v1`; HTTPS обязателен для удалённых серверов. DeepL поддерживает официальные Free и Pro адреса. Запросы не переключаются на другой сервис при ошибках.

В поле **Режим** выберите «Только перевод текста», «Распознавание текста (OCR)» или «Распознавание и перевод». Последние два варианта требуют модели с поддержкой изображений. **Сохранить** сохраняет подключение; **Сохранить и выбрать** также выбирает сервис для обычного перевода, результата и документов, а в режиме распознавания — ещё и для OCR. Вариант «Распознавание и перевод» получает исходный текст и перевод за один запрос к выбранной модели, без второго переводчика. Окно результата показывает фактически использованный сервис. Динамический режим сохраняет собственные настройки OCR.

Ключи отделены от JSON-настроек и привязаны к сервису и адресу: Windows Credential Manager, macOS Keychain, Linux Secret Service. В экспорт попадают только адрес, модель и параметры режима. Если хранилище недоступно, ключ действует до закрытия приложения; об этом сообщает экран сохранения. Для локального совместимого сервера ключ необязателен. Использование облачных API оплачивается по условиям сервиса.

Каталог перевода расширен с 16 до 63 языков; названия локализованы на восемь языков интерфейса и согласованы с Android-каталогом этого репозитория. Длинные списки имеют поиск по названию или коду и ограниченную высоту с прокруткой. Нажатие ↓ из поиска переводит фокус в результаты; Enter выбирает язык, Escape закрывает список. Названия входят в приложение; отдельно скачиваются только необходимые офлайн-модели. Поддержка конкретного языка зависит от движка: Windows проверяет каталог установленных возможностей, Tesseract — языковые пакеты, EasyOCR не предлагает неподдерживаемые модели.

Способ запуска перевода выделения настраивается в существующем режиме «Выделение», в окне его языковой пары; туда также ведёт **Настроить горячие клавиши → Режим выделения**. Поле **После выделения** предлагает горячую клавишу, кнопку рядом с текстом или немедленный перевод. Все варианты используют выбранный переводчик и языковую пару режима «Выделение»; отдельной модели и дополнительных галочек на странице перевода нет. По умолчанию используется горячая клавиша.

Протоколы сверены с первичной документацией: [OpenAI Images and vision](https://developers.openai.com/api/docs/guides/images-vision), [Gemini Image understanding](https://ai.google.dev/gemini-api/docs/image-understanding), [Claude Vision](https://platform.claude.com/docs/en/build-with-claude/vision), [DeepL Translate](https://developers.deepl.com/api-reference/translate/request-translation). Контракты API проверяются без платных сетевых запросов. Полноценная проверка качества конкретной облачной модели требует пользовательского ключа и отдельного запроса.
