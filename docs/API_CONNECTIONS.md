# Подключения API в десктопной версии

В «Основных настройках» находятся запуск, история, подсказки, обновления, показ и закрытие окна результата, масштаб и размер текста с примером. Во вкладке «Перевод и OCR» — движки, действия с выделением и три ряда общих кнопок. Нажмите **API-подключения**, чтобы настроить сервис.

Доступны OpenAI (Responses API), OpenAI-совместимый сервер (Chat Completions), Gemini, Claude и DeepL API. Ключ LibreTranslate также можно задать в этом окне. Для нейросетевого сервиса укажите точный ID доступной вам модели. Для собственного сервера задайте базовый адрес API, например `http://localhost:11434/v1`; HTTPS обязателен для удалённых серверов. DeepL поддерживает официальные Free и Pro адреса. Запросы не переключаются на другой сервис при ошибках.

Выберите сервис в списке **Перевод** для обычного текста, результата и документов. Для распознавания выберите его также в **OCR** и включите «Модель принимает изображения» только для модели с поддержкой изображений. Если включено «Распознавать и переводить одним запросом», выделенная область и полноэкранный перевод получают исходный текст и перевод за один запрос. Отдельный текстовый переводчик при этом не вызывается; обычный текст продолжает использовать выбранный переводчик. Окно результата показывает фактически использованный сервис. Динамический режим сохраняет собственные настройки OCR.

Ключи отделены от JSON-настроек и привязаны к сервису и адресу: Windows Credential Manager, macOS Keychain, Linux Secret Service. В экспорт попадают только адрес, модель и параметры режима. Если хранилище недоступно, ключ действует до закрытия приложения; об этом сообщает экран сохранения. Для локального совместимого сервера ключ необязателен. Использование облачных API оплачивается по условиям сервиса.

Каталог перевода расширен с 16 до 63 языков; названия локализованы на шесть языков интерфейса и согласованы с Android-каталогом этого репозитория. Длинные списки имеют поиск по названию или коду и ограниченную высоту с прокруткой. Нажатие ↓ из поиска переводит фокус в результаты; Enter выбирает язык, Escape закрывает список. Названия входят в приложение; отдельно скачиваются только необходимые офлайн-модели. Поддержка конкретного языка зависит от движка: Windows проверяет каталог установленных возможностей, Tesseract — языковые пакеты, EasyOCR не предлагает неподдерживаемые модели.

Быстрый перевод выделения включается отдельной галочкой. Без «Переводить выделение сразу» рядом с выделенным текстом появляется кнопка. С этой галочкой перевод начинается сразу. Оба варианта используют выбранный переводчик и языковую пару режима «Выделение»; отдельной скрытой модели нет.

Протоколы сверены с первичной документацией: [OpenAI Images and vision](https://developers.openai.com/api/docs/guides/images-vision), [Gemini Image understanding](https://ai.google.dev/gemini-api/docs/image-understanding), [Claude Vision](https://platform.claude.com/docs/en/build-with-claude/vision), [DeepL Translate](https://developers.deepl.com/api-reference/translate/request-translation). Контракты API проверяются без платных сетевых запросов. Полноценная проверка качества конкретной облачной модели требует пользовательского ключа и отдельного запроса.
