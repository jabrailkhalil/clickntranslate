# Настройка Click’n’Translate на Android

Мастер версии 0.3.2 содержит два шага и открывается при первом запуске и повторно через справку. После обновления с прежнего мастера он показывается один раз. Блок готовности на главном экране показывает разрешения, настройки сервиса и модели.

| Шаг | Что сделать | Куда ведёт кнопка |
| --- | --- | --- |
| 1. Внешний вид | Выбрать язык интерфейса и тему | Встроенный выбор языка и оформления |
| 2. Языки | Выбрать оригинал и перевод, прочитать краткую инструкцию | Главный экран |

Мастер сохраняет ранее выбранный сервис; новая установка использует Google. Разрешения, движок OCR и модели не входят в первый запуск. Разрешение поверх приложений запрашивается при использовании перевода экрана. Уведомления, специальные возможности, батарея и модели настраиваются по мере необходимости через главный экран и настройки.

При первом запуске захвата Android запросит согласие на демонстрацию экрана. Для перевода поверх других приложений в Android 14+ выбери весь экран. Защищённые системные окна и приложения могут запрещать захват. Запрос согласия появляется по правилам Android; приложение не выдаёт его самостоятельно.

На Android 13+ для APK, установленного вручную, система может потребовать сначала разрешить ограниченные настройки на странице приложения, прежде чем включить специальные возможности. На разных устройствах путь и название пункта отличаются. Этот доступ нужен для дополнительных действий, включая управление кнопками громкости и перевод ввода; для обычного перевода текста он не требуется.

## Разделы и возможности

| Возможность | Где находится | Условия |
| --- | --- | --- |
| Перевод экрана и области | Экран → Запустить | Разрешение поверх приложений и согласие на захват |
| Перевод введённого текста | Текст | Сервис и допустимая пара языков |
| Перевод фотографий | Экран → Фото либо системное «Поделиться» | Доступ к выбранным изображениям; OCR и сервис перевода |
| История текста | История | До 50 записей локально; можно очистить |
| История задач фото | История → Фото | Сохранённые задачи галереи |
| Google, Lingva, MyMemory, LibreTranslate | Настройки → Сервис | Интернет; MyMemory требует явный язык оригинала |
| API-сервисы | Настройки → Сервис | Собственные учётные данные выбранного поставщика |
| Офлайн-перевод ML Kit | Сервис → ML Kit → Модели | Явный язык оригинала и загруженные языковые модели |
| Локальные LLM | Сервис → Sakura / HY-MT2 → Модели | Android 13+, подходящая модель, достаточно памяти и места |
| Другие движки OCR | Расширенные настройки → OCR | Условия зависят от движка: модель, сервер либо API-ключ |
| Shizuku | Настройки → Захват | Установленный и запущенный Shizuku; предоставленный доступ |
| Озвучивание | Расширенные настройки | Системный TTS либо выбранный API-провайдер |
| Словари и глоссарий | Настройки | Пакеты словарей либо сетевой поиск; собственные термины |
| Профили, импорт и экспорт | Расширенные настройки | Ключи сервисов остаются локальными |
| Диагностика | Настройки → Журнал | Экспорт по действию пользователя |

Названия языков перевода показываются на языке интерфейса. Доступность конкретной пары зависит от сервиса. Для ML Kit список ограничен поддерживаемыми языками. Интерфейс доступен на английском, русском, немецком, французском, испанском и китайском.

Публичные серверы Google, Lingva, MyMemory и LibreTranslate могут ограничивать запросы или быть недоступны. В настройках Lingva и LibreTranslate можно указать собственный сервер. Проверка соединения отправляет короткую пробную фразу выбранному сервису.

## Если перевод не появился

1. Проверь пару языков и связь с сервисом в его настройках.
2. Проверь OCR и наличие модели для письменности оригинала.
3. Для экрана проверь разрешение поверх приложений и повторно запусти захват.
4. Если кнопка исчезает в фоне, открой параметры батареи для приложения и проверь ограничения производителя телефона.
5. При смене сервера LibreTranslate проверь ключ для нового адреса; профиль не должен переносить ключ на другой сервер.


## Оформление и значок

В разделе «Оформление» доступны системная, светлая, тёмная, AMOLED и готовые бумажные темы Komi Store: день, ночь и Nord. Язык интерфейса меняется сразу, включая диалоги и панели. Доступны русский, английский, немецкий, французский, испанский и китайский.

«Логотип и значок на рабочем столе» предлагает оригинальный CT и варианты Океан, Мята и Закат. Название под значком — Clickn. Персонажи и собственные картинки выбираются отдельно для плавающей кнопки; доступны размер и прозрачность. Кнопка скрывается через 45 секунд бездействия. Вернуть её можно кнопкой «Показать кнопку» в приложении или уведомлении захвата. Для постоянного отображения включи соответствующий переключатель.

Глоссарий открывается с режимов «Свои термины», «Исправленные переводы» и «Не переводить надписи». У каждого есть пояснение и свой список. Большой набор японских звуков включается отдельно и не заполняет пользовательские записи. Неизменённые встроенные записи прошлой сборки скрыты; исправленные и собственные записи сохраняются.

## Проверочная версия

Пакет `dev.clickn.translate.preview` устанавливается отдельно от версии 0.2.0. Выдай ему разрешения и настрой выбранный сервис; его модели и настройки хранятся отдельно. Последующие Preview-сборки используют сохранённую подпись и могут обновлять эту установку.
