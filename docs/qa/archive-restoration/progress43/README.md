# Click’n’Translate Android 1.8.3 (code43)

В режиме автоперевода приложение показывает индикатор во время обработки принятого кадра. Индикатор связан с актуальным запросом и убирается при остановке цикла. Исходники `6d61cc8da5d7a9f7680a41fda784fd49b1e67c2f`.

Gradle собрал Debug, AndroidTest и Release за 19 мин 34 с. Прошли 1 894 JVM-теста и 110 из 115 инструментальных тестов. Пять инструментальных проверок пропущены по условиям запуска. Lint завершился с 0 ошибок, 975 предупреждениями и 42 информационными записями. [Сборка](build.json) · [JVM и lint](unit-and-lint.json) · [Инструментальные тесты](instrumentation.json).

APK подписан действующим сертификатом приложения `dev.clickn.translate`. Проверены подпись v2/v3, ZIP-выравнивание 16 КБ и заголовки ELF. SHA-256 файла `fe3087c1132e367490be24117688d279addf085c377f9da5f83117f95a4d4efe`. На эмуляторе API 36 code43 обновил code42 с сохранением времени первой установки. [APK](../../../../artifacts/android/1.8.3-code43/ClicknTranslate-Android-1.8.3-code43-candidate.apk) · [Подпись](signature.txt) · [Установка](install.json).

Во время обработки первой страницы системный список окон и снимок подтвердили видимый индикатор. Оба результата появились между замерами на 35,64 и 42,58 с. В отдельном прогоне code42 оба результата уже были видны на отметке 29,45 с. Два замера различаются, причина разницы не установлена. Смена страницы и возврат переведены к 15,94 и 15,84 с. [Индикатор](c43-first-page-01.png) · [Первый перевод](c43-first-page-06.png) · [Замеры](automatic.json).

Автоперевод следующей страницы остановлен касанием героя во время обработки. Индикатор исчез, захват остался активным. После ожидания 12 с экран показывал исходную страницу без позднего перевода. Отдельная кнопка Stop освободила MediaProjection. [Экран после отмены](c43-after-loop-cancel.png) · [Состояние захвата и индикатора](automatic.json).

На обычном эмуляторе System UI завис при открытии вкладки «Текст» на code42. Создание записи до обновления в этом прогоне не подтверждено. [Системный диалог](c43-upgrade-history-before-text-tab.png).

На отдельном эмуляторе API 36 с размером страницы 16 КБ первая попытка автоматизации не открыла вкладку «Текст». В ручном прогоне запись создана на code41. После подписанного обновления до code43 и холодного запуска сохранились исходная фраза, русский перевод, время записи и время первой установки. Проверена одна тестовая запись. [До обновления](history-16k/c43-history16k-before-row.png) · [После](history-16k/c43-history16k-after-row.png) · [Результаты](history-16k/result.json).

Сетевой Google Translate сохранил введённую фразу и показал ошибку подключения при отсутствии активной сети. Старый результат исчез. В диагностике показан `TF_OFFLINE_DNS` без текста запроса и URL. После восстановления сети «Try again» перевела ту же фразу. Затем загружена пара ML Kit EN→RU. Новая фраза переведена при отключённых Wi‑Fi и мобильных данных. Модель передала *stands* словом «подходит» вместо «стоит». Проверка подтверждает работу без сети на одной паре. Сетевые настройки и исходный сервис восстановлены. [Ошибка подключения](offline/c43-offline-disconnected.png) · [Повтор](offline/c43-offline-retry-result.png) · [Локальный результат](offline/c43-offline-mlkit-proof-0.png) · [Отчёт](offline/result.json).

Фотоперевод подтверждён на одном PNG 1080 × 2400. Android Photo Picker передал изображение, Auto OCR распознал оба английских абзаца, Google перевёл их на русский. Экспорт через системный выбор папки сохранил PNG тех же размеров. При просмотре под стандартной тёмной подложкой видны английские буквы. В двух контрольных прямоугольниках на белом исходнике получен RGB 25, на чёрных пикселях RGB 0.
