# Click’n’Translate Android 1.8.3 (code44)

PNG-экспорт и предпросмотр фото теперь используют ту же классическую тёмную подложку, что и экранный перевод. При стандартной прозрачности подложка полностью закрывает исходник внутри области заливки. Пользовательская настройка прозрачности учитывается. JPEG-кэш предпросмотра получил новую версию, чтобы исправление применилось к сохранённым задачам. Исходники сборки `5a578d60e68518c8891345ad62376d7c1540ca49`.

SHA-256 приложения Debug до и после совпадает. В финальном прогоне прошли 110 из 115 тестов, 5 пропущены по условиям запуска.
