# Доступность движков и обновлений

Проверка 27 ноября 2026 года через обычную логику клиента 1.8.3. Для сетевых переводчиков использовались пустая конфигурация, отключённый кэш и тестовое предложение «Good morning. Thank you very much.». Ни одному сервису не передавали пользовательский текст или ключ.

| Онлайн-переводчик | Домашнее подключение | GitHub |
| --- | --- | --- |
| Google | «Доброе утро. Большое спасибо.» | Тот же перевод |
| MyMemory | «Доброе утро. Большое спасибо.» | Тот же перевод |
| Lingva | Публичные узлы вернули ошибку, последний ответ HTTP 502 | HTTP 502 |
| LibreTranslate | У стандартного публичного сервера Disroot ответ HTTP 502 | HTTP 502 |

Для Lingva и LibreTranslate результат относится к публичным точкам доступа на момент проверки. LibreTranslate также поддерживает свой сервер или настроенное подключение с ключом. Доступность этих пользовательских подключений зависит от их владельцев. ## Загрузка проверенных пакетов

Свежий клиент проверил цепочку подписей TUF и выбрал пакеты по версии 1.8.3, платформе, архитектуре и стабильному каналу. Получена ревизия каталога 4. Полностью скачаны 158 уникальных файлов (3 921 029 149 байт в сумме). Для каждого сравнили полный размер и SHA‑256 с подписанным каталогом. Все 158 совпали. Для трёх крупных файлов после обрыва TLS содержимое повторно прочитали диапазонами и сверили полный SHA‑256. [Таблица хешей](catalog-full-downloads.json) · [Версии и сроки действия подписанных метаданных](catalog-expirations.json)

| Платформа | Что сейчас выдаёт канал stable |
| --- | --- |
| Windows x64 | RapidOCR, EasyOCR, Tesseract, Argos, Hy‑MT |
| Linux x64 | 0 совместимых записей |
| macOS Apple Silicon и Intel | 0 совместимых записей на каждой архитектуре |

Пользователи Linux и macOS могут пользоваться встроенными, системными, установленными вручную и онлайн-движками в пределах возможностей платформы. Чистая установка перечисленных дополнительных движков через стабильный центр требует публикации подписанных пакетов для соответствующей платформы. На Linux проверка обновления теперь дожидается уже запущенной загрузки каталога.
