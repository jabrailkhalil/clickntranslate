## Прежний PowerShell-сценарий обновления ZIP

Штатная установка Windows в 1.8.2 и 1.8.3 вызывает C#-компонент ClicknTranslateUpdater.exe через _launch_apply_updater. Скрипт _launch_zip_updater проверяют отдельные тесты прежнего механизма. В журнале этого скрипта на Windows Server после остановки приложения три теста завершили распаковку одной ошибкой. Модуль Microsoft.PowerShell.Archive 1.2.7 пытается вызвать трёхаргументную перегрузку ExtractToDirectory, которая недоступна встроенному Windows PowerShell 5.1 на .NET Framework. Возникает откат до копирования новых файлов. Выбор рабочего каталога и остановка занятого OCR-worker прошли. [Результат каждого теста в JUnit](ci-run-46004716380/tests-Windows-part-6-results.xml)

Тот же сбой воспроизведён локально на опубликованном пакете Microsoft.PowerShell.Archive 1.2.7. Его SHA-512 совпал с индексом PowerShell Gallery, авторскую подпись пакета подтвердил NuGet. С тем же модулем на исходном `eec0ed7` провалились все три проверки, а на `60ff416a453a57505c40dcd34d0997d4e68c6dc9` прошли все три. Исправление использует двухаргументную перегрузку .NET для распаковки в индивидуальный пустой каталог. Она также используется программой восстановления ClicknTranslate. На исправлении прошли 67 тестов обновления, подтверждения запуска и восстановления. [До](final/ps127-before/results.xml), [после](final/ps127-after/results.xml), [67 тестов](final/windows-updater-fixed/results.xml), [верификация подписи](ps127-signature.json), [пакет в PowerShell Gallery](https://www.powershellgallery.com/packages/Microsoft.PowerShell.Archive/1.2.7).

Интеграционный коммит, включающий исправление ZIP updater и общие изменения верстки, — `05c30f30bc288b7b9ce582ae5952c3315f5fdb82`. [Матрица этого коммита](https://github.com/jabrailkhalil/clickntranslate/actions/runs/46006833564).

## Штатный переход 1.8.2 → 1.8.3

Чистый Windows Server 2022 запустил C#-компонент из опубликованной 1.8.2. SHA-256 исполняемого помощника совпал с независимо проверенной копией из публичного ZIP: `f23a8b61fe8bcf37b2ca7f4b950c25c4cd4f8be8f6e362795505c16da8dffa01`. Новый ZIP собран из `05c30f30bc288b7b9ce582ae5952c3315f5fdb82`, размер 282 501 472 байта, SHA-256 `c241951dac726874a8f10678f1916a3f09a829afc22cf2c8ee985050d0612e33`. После обновления проверены все 4206 файлов дистрибутива, из настроек сохранились язык, масштаб, тема и автозапуск, а также три бинарных маркера в data, ocr и translators. Старая и обновлённая программы подтвердили версии из живого GUI и продолжили работу после подтверждения. Тест передал архив установленному помощнику через его штатный командный интерфейс. [Подтверждение перехода](native-transition-46007997038/update-audit/zip-182-to-183/result.json), [сборка и SHA-256](native-transition-46007997038/transition-fixtures/build-receipt.json).

Во втором случае после установки повреждённой тестовой копии GUI C#-помощник обнаружил неверную версию исполняемого файла и запустил откат. Восстановленные 4065 файлов совпали с публичным архивом, версия 1.8.2 снова подтвердила запуск, настройки и все три маркера сохранились. [Подтверждение отката](native-transition-46007997038/update-audit/zip-182-rollback/result.json), [журнал](native-transition-46007997038/update-audit/zip-182-rollback/updater.txt). [Прогон](https://github.com/jabrailkhalil/clickntranslate/actions/runs/46007997038).
