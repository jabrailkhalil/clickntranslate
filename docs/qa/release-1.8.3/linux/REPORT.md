Использовались контролируемые синтетические тексты и закрытые профили. Динамический захват отрабатывался на X11. В Wayland фактически проверены окно, портал, смешанный DPI и буфер обмена; проверка полномасштабной сессии GNOME/KDE с физическими мониторами в этот прогон не входила. Подготовленная модель Argos проверяет автономную обработку после установки. Доставку модели из действующего сервиса и автоматический переход 1.8.2 через публичный production-канал этот прогон не подтверждает.
