## OCR и интерфейс

Из финального коммита на Windows запустили приложение через штатный ClicknTranslate.exe в отдельной оконной станции. На Ubuntu собранный AppImage дважды стартовал с пустыми профилями под X11. В обоих прогонах проверены пять вкладок, списки, центр движков, четыре локали, обе темы и процессы OCR и перевода. На Linux штатный Tesseract прочитал «NATIVE OCR CHECK» как в полноэкранном, так и в абзацном режиме. Дополнительный сеанс Sway на сборке `05c30f3` проверил иероглифы и повторное открытие того же окна. [Готовый Windows-пакет](windows/candidate-7cd32e563/report.json) · [Два запуска AppImage](linux/final-7cd32e5/summary.json) · [Окно в Wayland](linux/final-05c30-wayland/report.json)

На узких горизонтальных фрагментах английского и русского текста RapidOCR терял начальные буквы. На одних и тех же 12 изображениях количество полностью правильных строк выросло с 8 до 12. Для других языков и полноэкранных изображений сохранились прежние параметры детектора. Отдельно проверен фактический результат рабочего процесса распознавания. [Сравнение параметров](windows/rapidocr-detector-limits.json) · [Проверка через OcrWorker](windows/rapidocr-release-windows.json)

На macOS при первом открытии выпадающий список языков занимал 640 px при ширине поля 306 px. После исправления при первом и повторном открытии размеры совпадают. На минимальной Ubuntu в китайском интерфейсе появились читаемые иероглифы. Исправлены размеры арабских вкладок, португальского уведомления и образца шрифта. Повреждённое значение темы в конфигурации теперь восстанавливается при старте с сохранением языка, масштаба и остальных настроек. Исправление выбирает короткий личный адрес для каждой сессии. На Apple Silicon, Intel и Ubuntu прошли по 42 проверки, включая второй процесс и два разных пути с Unicode. ## Проверка обновления Windows

На чистой Windows Server 2022 штатный C#-обновлятор из публичного ZIP 1.8.2 установил кандидат `05c30f3`. Сверены все 4 206 файлов ZIP и SHA‑256 самого запущенного помощника. Новый GUI подтвердил 1.8.3, сохранил настройки, данные и модели. В отдельной проверке повреждённый тестовый GUI вызвал настоящий откат. После него совпали все 4 065 файлов исходного ZIP, а работающий GUI снова подтвердил 1.8.2. В обоих случаях запускался прежний помощник без подмены. [GitHub Actions](https://github.com/jabrailkhalil/clickntranslate/actions/runs/46007997038) · [Установка](windows/native-transition-46007997038/update-audit/zip-182-to-183/result.json) · [Откат](windows/native-transition-46007997038/update-audit/zip-182-rollback/result.json)

Обновлён и список проверок следующего релиза Windows. Раньше GitHub запускал переходы только по 1.8.1 включительно, а скрипт приёмки сверял результаты лишь по 1.8.0. Теперь у планирования и приёмки один список. Для кандидата 1.8.3 в нём десять сочетаний исходной версии и формата установки, включая ZIP и Setup публичной 1.8.2. Инфраструктурная проверка плана охватила кандидаты 1.8.1, 1.8.2 и 1.8.3. [Изменение](https://github.com/jabrailkhalil/clickntranslate/commit/0f5b63e17a6e9bebb51d1cbb49cce29dfffb9a52) · [Локальная проверка](windows/update-matrix/results.xml)

## Внешние сервисы и распространение

- Получены все 158 файлов, перечисленные в свежем подписанном каталоге, всего 3 921 029 149 байт. Размер и SHA‑256 совпали у каждого. В стабильном канале установщик предлагает пять движков для Windows x64. Для Linux x64 и обеих архитектур macOS канал вернул ноль совместимых записей. Встроенные, системные и установленные локально движки проверялись отдельно. [Каталог по платформам и сетевые тесты](engines.ru.md)
- С двух независимых сетей Google и MyMemory перевели контрольную фразу с английского на русский. Публичные узлы Lingva и LibreTranslate на момент проверки ответили HTTP 502. [Результаты](engines.ru.md)
- Строгая проверка целостности подписи macOS прошла. Gatekeeper отклонил постоянную самоподпись. На Apple Silicon у копии с атрибутом загрузки браузером приложение не подтвердило запуск за 35 секунд. Для штатного публичного распространения без ручного исключения нужна подпись Developer ID и нотарификация. Для проверки первого ручного разрешения записи экрана и управления, а также его сохранения после обновления нужен один интерактивный Mac. [Проверка Gatekeeper](https://github.com/jabrailkhalil/clickntranslate/actions/runs/46009103028) · [Developer ID](https://developer.apple.com/developer-id/)
- Windows-пакет и Android APK проверялись как частные кандидаты. Для Android переход с 1.8.2 проверен с одинаковой тестовой подписью. Физический OnePlus использует страницы 4 КиБ. Отдельной проверке перед распространением подлежат финальные производственные подписи, обновление публичного Android APK и запуск на реальном устройстве с 16 КиБ. [Windows](windows/Windows-QA.md) · [Android](android/README.ru.md)
- Таблица скачивания подготовлена к будущему релизу. Проверочный пример построен из фактических файлов публичной 1.8.2. Ссылки VirusTotal используют SHA‑256 каждого файла, счётчик скачиваний относится к конкретному тегу и имени. [Пример таблицы](download-table.md)
