# Выпадающие списки — нативная проверка 7 сентября 2026

`before-geometry.txt` — исходный Cocoa-прогон: первое открытие смещено относительно
повторного, динамический каталог имеет высоту одной строки. `after-geometry.txt`
— тот же диагностический сценарий после исправления.

`source-smoke.json` и `installed-smoke.json` содержат по 400 снимков,
включая 90 случаев / 180 открытий списков. Автоматически проверены привязка
к полю, границы доступной области, совпадение первого и второго открытия,
достижимость последней строки прокруткой. Оба прогона используют настоящий Cocoa.

Выбранные PNG здесь получены из установленного в `/Applications` приложения.
Полные матрицы и журналы доступны в локальном архиве
[`Click-n-Translate-1.7.1-macos-arm64-QA.zip`](/Users/jabrail/Desktop/click/clickntranslate/releases/Click-n-Translate-1.7.1-macos-arm64-QA.zip).
Главное окно включает позицию списка; для отдельных диалогов сохранён popup.
Это Qt-отрисовка и локальные события приложения, а не проверка физических
горячих клавиш, выдачи TCC-разрешений или взаимодействия со сторонними окнами.

`installation-qa.json` подтверждает установку из DMG и подпись, `lifecycle-qa.json`
— обычный запуск, IPC и второй экземпляр. Числа тестов, архитектура и текущие
SHA-256 находятся в `validation.json`. Полные ограничения: [MACOS_QA.md](../../../MACOS_QA.md).
