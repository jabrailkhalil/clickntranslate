# Запись экрана: включённый переключатель и отказ API

В новом процессе установленной `.app` обе проверки разрешений возвращали
`false`. Бинарник и подпись после пользовательского сообщения не менялись.
В `user-hotkey-events.txt` видны два нажатия/отпускания перевода области из
обычного пользовательского запуска; ввод этих событий агент не синтезировал.

Старая запись ScreenCapture сброшена штатной командой `tccutil` только для
`io.github.jabrailkhalil.clickntranslate`. Приложение перед этим штатно завершено.
Настройки Screen Recording и текущая `.app` в Finder открыты. Выдача разрешения
остаётся системным действием пользователя; она не обходится редактированием TCC.

На момент записи ожидаются повторное добавление текущей `.app`, включение доступа
и нативная проверка. Для постоянства разрешений между сборками нужен стабильный
сертификат подписи; на этом Mac `security find-identity -v -p codesigning`
возвращает 0 valid identities. См. [ответ Apple DTS](https://developer.apple.com/forums/thread/819406).
