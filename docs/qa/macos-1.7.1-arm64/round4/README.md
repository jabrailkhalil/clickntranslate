# Горячие клавиши — нативная проверка 7 сентября 2026

Причина: перепутаны номера событий Carbon; нажатие — 5, отпускание — 6
(`sdk-constants.json`, извлечены из установленного Apple SDK).

`dispatch-before.txt` — воспроизведение старого дефекта настоящим Carbon:
отпускание до любого нажатия ошибочно вызвало действие. `dispatch-after.txt` —
десять нажатий после исправления, с проверкой удержания, отпускания и повторной
регистрации. События направляются через `SendEventToEventTarget` в собственный
установленный обработчик приложения; глобальный ввод не синтезируется.

Полный Cocoa pytest: 1040 passed, 72 skipped, 892 subtests. Отдельный процесс
проверяет конфликт регистрации горячей клавиши и её освобождение после выхода.
Проверка конфликтов внутри одного процесса этого сценария не покрывает.

Нативный smoke теперь проверяет обработку событий в frozen `.app`, а не только
успешный вызов `RegisterEventHotKey`. Проверка физической клавиатуры остаётся
отдельным сценарием. См. [MACOS_QA.md](../../../MACOS_QA.md).
