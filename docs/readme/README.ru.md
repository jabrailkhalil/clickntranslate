# Click'n'Translate

Бесплатный экранный переводчик с открытым исходным кодом для **Windows, Linux и macOS**. Распознавайте текст в приложениях, изображениях и играх, переводите выделенное или следите за меняющимся текстом в нескольких областях экрана.

## Возможности

- OCR с экрана, перевод выделенного текста, полноэкранное наложение и динамический перевод нескольких областей.
- Онлайн-перевод и локальное распознавание; офлайн-перевод после загрузки языковых моделей.
- Перевод документов, настраиваемые сочетания клавиш и компаньон на рабочем столе.
- Светлая и тёмная темы, шесть языков интерфейса и отдельные параметры окон для каждого режима.
- **В 1.8.0:** единое приветственное окно, аккуратный выбор языков, исправления динамического наложения, помощь с разрешениями macOS и тонкие полосы прокрутки во всём приложении.

Окно документов открывает `.txt`, `.md`, `.docx`, `.pdf`, `.html`, `.htm` и `.rtf`. Исходник и перевод можно редактировать рядом, а исходник — скрыть, уменьшив окно. В настройках доступны импорт и экспорт параметров, а также отдельное включение локальных историй.

## Горячие клавиши

| Комбинация по умолчанию | Действие |
| --- | --- |
| `Ctrl + Alt + C` | Распознать текст в области и скопировать его |
| `Ctrl + Alt + T` | Выделить область, распознать и перевести текст |
| `Ctrl + Alt + F` | Перевести весь экран |
| `Ctrl + Alt + Q` | Перевести выделенный текст в активном приложении |
| `Ctrl + Shift + Q` | Заменить выделенный текст его переводом |
| `Ctrl + Shift + Space` | Показать или скрыть Click'n'Translate |
| `Ctrl + Alt + G` | Запустить или остановить динамический перевод выбранных областей |

Все комбинации меняются или очищаются в разделе **Настройки → Настроить горячие клавиши**. Пары языков отдельно запоминаются для OCR, выделенного текста, замены, всего экрана и динамического перевода.

В таблице указаны комбинации Windows. На **macOS** вместо Ctrl используется **Command**, вместо Alt — **Option**. На **Linux** назначьте соответствующие команды в настройках сочетаний клавиш рабочего стола: [инструкция](../../docs/LINUX.md).

## Переводчики и OCR

| Тип | Движки | Для чего подходят |
| --- | --- | --- |
| Онлайн-перевод | Google, MyMemory, Lingva, LibreTranslate | Быстрый перевод без загрузки модели |
| Офлайн-перевод | Argos Translate, Hy-MT | Приватный перевод после установки выбранных пакетов |
| OCR | Windows OCR / Apple Vision, Tesseract, RapidOCR, EasyOCR | Распознавание разных языков и типов изображений |

В разделе **Настройки → Языковые пакеты** можно устанавливать и удалять движки OCR, языки распознавания и модели офлайн-перевода. Загружаются только выбранные пакеты; установленные офлайн-движки работают без интернета. Системное распознавание — Windows OCR на Windows и Apple Vision на macOS. Доступность онлайн-переводчиков зависит от выбранного сервиса.

## Начало работы

1. Скачайте вариант для своей системы и откройте приложение. Python уже включён в сборку.
2. Выберите движок OCR, переводчик и языки в настройках. Для офлайн-перевода загрузите языковые модели.
3. Выберите захват или перевод. На Mac приложение поможет открыть разрешения **«Запись экрана»** и **«Универсальный доступ»**. На Linux настройте сочетания клавиш через окружение рабочего стола: [инструкция](../../docs/LINUX.md).

Распознавание выполняется локально. Онлайн-перевод отправляет текст выбранному провайдеру; для локального перевода используйте офлайн-движок. Подробнее: [конфиденциальность](../../PRIVACY.md).
