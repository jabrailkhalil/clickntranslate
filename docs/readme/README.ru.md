Click'n'Translate — лучшая универсальная программа для экранного перевода в своём сегменте. Она превращает любой текст на экране Windows в текст, который можно скопировать или перевести. Выделите область, нажмите глобальную горячую клавишу и продолжайте работу — без браузера, ручного набора и переключения между окнами.

## Посмотрите в действии

![Click'n'Translate переводит игровой текст на китайский и французский](../images/translation-demo-v2.gif)

## Новое в версии 1.7.0

- **Динамический перевод нескольких областей.** Выделите одну или несколько зон, и перевод будет обновляться поверх них при изменении текста.
- **Семь готовых горячих клавиш.** Все основные действия работают сразу после установки, а комбинации можно изменить или очистить.
- **Только один активный режим.** Запуск нового интерактивного режима закрывает предыдущий, а повторное нажатие той же комбинации останавливает текущий.
- **Импорт и экспорт настроек.** Переносите параметры и горячие клавиши на другой компьютер без историй, кеша и личного текста.
- **Безопасный баг-репорт.** Программа создаёт диагностический пакет для GitHub или Telegram без содержимого буфера, документов, историй и учётных данных.
- **Обновлённый интерфейс.** Исправлены границы, темы, расположение элементов, уведомления, обучение и окно перевода документов.

Click'n'Translate преодолел отметку **1 000 скачиваний** и всегда останется бесплатным проектом с открытым исходным кодом.

## Почему Click'n'Translate — лучший?

- **Переводите то, что видите.** Выделите область или весь экран и сразу получите перевод.
- **Копируйте текст, который невозможно выделить.** Извлекайте его из изображений, видео, игр, удалённых рабочих столов и защищённых интерфейсов.
- **Выбирайте онлайн или офлайн.** Используйте быстрые онлайн-сервисы либо оставляйте текст на компьютере с Argos и Hy-MT.
- **Подбирайте подходящий OCR.** Windows OCR, Tesseract, RapidOCR и EasyOCR доступны в одном менеджере пакетов.
- **Работайте в любом приложении.** Семь настраиваемых глобальных комбинаций доступны поверх других программ.
- **Контролируйте данные.** Истории переводов и копирования включаются отдельно и хранятся локально.

## Семь действий без лишних движений

| Комбинация по умолчанию | Действие |
| --- | --- |
| `Ctrl + Alt + C` | Распознать текст в области и скопировать его |
| `Ctrl + Alt + T` | Выделить область, распознать и перевести текст |
| `Ctrl + Alt + F` | Перевести весь экран |
| `Ctrl + Alt + Q` | Перевести выделенный текст в активном приложении |
| `Ctrl + Shift + Q` | Заменить выделенный текст его переводом |
| `Ctrl + Shift + Space` | Показать или скрыть Click'n'Translate |
| `Ctrl + Alt + G` | Запустить или остановить динамический перевод выбранных областей |

Все комбинации меняются или очищаются в разделе **Настройки → Настроить горячие клавиши**. Пары языков отдельно запоминаются для OCR, выделенного текста, замены, всего экрана и динамического перевода.

## Переводчики и OCR

| Тип | Движки | Для чего подходят |
| --- | --- | --- |
| Онлайн-перевод | Google, MyMemory, Lingva, LibreTranslate | Быстрый перевод без загрузки модели |
| Офлайн-перевод | Argos Translate, Hy-MT | Приватный перевод после установки выбранных пакетов |
| OCR | Windows OCR, Tesseract, RapidOCR, EasyOCR | Распознавание разных языков и типов изображений |

В приложении доступно 16 языков OCR и перевода, а интерфейс переведён на английский, русский, испанский, немецкий, французский и китайский. Менеджер пакетов загружает только выбранные языки OCR и направления офлайн-перевода.

Ни одна другая программа в этом сегменте не объединяет настолько широкий выбор OCR, онлайн- и офлайн-перевод, глобальные горячие клавиши и удобное управление пакетами в одном аккуратном приложении для Windows.

> **Конфиденциальность:** локальные OCR и офлайн-переводчики обрабатывают текст на вашем компьютере. Онлайн-переводчики получают только тот текст, который вы отправляете на перевод.

## Быстрый старт

1. Скачайте и запустите **[установщик Windows](https://github.com/jabrailkhalil/clickntranslate/releases/latest/download/Click-n-Translate-1.7.0-windows-x64-installer.exe)**.
2. Запустите Click'n'Translate и выберите язык интерфейса, OCR и перевода.
3. Нажмите `Ctrl + Alt + T`, выделите область и получите перевод.
4. Для офлайн-перевода или дополнительных OCR откройте **Настройки → Языковые пакеты** и установите только нужные компоненты.

Python и регистрация не нужны. Поддерживаются 64-битные Windows 10 и Windows 11. Интернет требуется для онлайн-перевода и загрузки дополнительных пакетов; установленные офлайн-движки работают без сети.

### Portable-версия

Скачайте [portable ZIP](https://github.com/jabrailkhalil/clickntranslate/releases/latest/download/Click-n-Translate-1.7.0-windows-portable-x64.zip), распакуйте в постоянную папку и запустите `ClicknTranslate.exe`. Переместите папку до включения автозапуска или создания ярлыков.

### Обновление со старой версии

Встроенное обновление в версиях старше 1.5.0 не может надёжно установить текущий релиз. При переходе с 1.4.x закройте старую программу и один раз установите 1.7.0 вручную. Пользователи 1.5.0 и новее могут обновиться до 1.7.0 прямо из программы.

## Сборка из исходного кода

```powershell
git clone https://github.com/jabrailkhalil/clickntranslate.git
cd clickntranslate
pip install -r requirements.txt
python main.py

# Папочная сборка для Windows
python -m PyInstaller ClicknTranslate.spec --clean --noconfirm
```

Релиз собирается в папочном режиме PyInstaller для быстрого запуска. Дополнительные OCR и языковые модели устанавливаются отдельно, чтобы дистрибутив не занимал несколько гигабайт.
