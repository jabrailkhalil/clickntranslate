## Platform use

- GitHub README and landing page: use the GIFs directly.
- Product Hunt: use a real GIF as the thumbnail only if it remains under the
  current 3 MB limit; use the real recordings as gallery media when the form
  accepts GIF uploads.
- AlternativeTo and other directories: upload a real GIF when accepted. If a
  site only accepts a still image, export a frame from the same recording; do
  not replace it with a generated mockup.
- Reddit, Habr, and social posts: attach the single recording that directly
  demonstrates the workflow discussed in that post.

Before uploading, inspect the full loop for private text, usernames,
notifications, unrelated windows, and third-party material that should not be
published.
